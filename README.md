## 编译与启动

安装 JDK 21+；当前工作区已有独立的 `.tools/jdk-21...`，脚本会优先使用它，不修改全局 Java。

Windows PowerShell：

```powershell
./scripts/build.ps1
./scripts/start.ps1 -Mode dispatch -NoConsole
```

构建默认最多使用 4 个独立 Java 进程运行测试；每个进程内的测试仍顺序执行。
可用 `./scripts/build.ps1 -TestForks 1` 顺序运行，或用
`./scripts/build.ps1 -RerunTests` 强制重跑测试而复用未改变的编译结果。
其他系统使用 `-PtestForks=1` 调整测试进程数量，范围为 1 至 4。

其他系统：

```sh
./gradlew test shadowJar
java -jar build/libs/hkrpg-server.jar --mode=dispatch --no-console
```

编译产物：`build/libs/hkrpg-server.jar`。

Dispatch 模式不需要游戏资源，默认监听 `127.0.0.1:8080`。游戏模式需要与所选 `protocol.wireVersion` 匹配的资源。4.6 实验配置见 [configs/client-4.6.example.json](configs/client-4.6.example.json)，请合并所需字段到现有配置，不覆盖运营配置。

```powershell
./scripts/start.ps1 -Check
./scripts/start.ps1 -NoConsole -NoHandbook
```

`-Check` 只检查配置及资源，不启动数据库、HTTP 或游戏监听。缺失资源时退出码为 1。首次读取配置会创建 `config.json`；损坏的配置不会被默认值覆盖。

本地访问：

- `/health/live`：HTTP 服务存活。
- `/health/ready`：启动就绪。
- `/status/server`：人数、容量和协议基线。
- `/api/features`：功能状态、源码证据和已知缺口。
- `/api/feature-backlog`：每个请求入口的参考来源、固定提交及待验收状态。
