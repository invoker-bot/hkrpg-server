# 剧情变量动作的溢出预检

`SetCustomValue`、`AddCustomValue` 的执行顺序及显式 `delSubMission`/`delMission` 子任务链，现在共用一份临时变量快照进行预检。加法超出有符号32位范围时，返回已有 `MISSION_FINISH_WAY_NOT_MATCH`，在预检阶段不修改变量、完成子任务、保存玩家或预约执行记录。合法边界值仍按原值保存，不截断或回绕。

预检从保存游标的下一动作开始；已经完成的子任务不再模拟，重复引用或循环引用只检查一次。父任务前序修改会参与子任务计算，子任务修改也会参与父任务后序计算。实际执行每条变量动作前再次检查当前值，避免其他已支持动作的间接变化导致溢出后留下预约记录。

新增14项Java回归，其中8项先出现真实断言失败。覆盖正负溢出、前序赋值、父子任务顺序、合法上下界、已执行前缀、JSON保存恢复、重复子任务与已完成子任务。采用明确构造的边界场景；未增加剧情协议字段，也未证明原始全部剧情脚本或真实游戏UI可完成。整个剧情仍是部分实现，未知完成动作继续拒绝执行。
