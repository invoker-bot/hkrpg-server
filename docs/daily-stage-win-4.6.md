# 4.6 日常委托的关卡族胜利

原始3011012、3011112、3011602、3011607的StageWin参数201212、201311、20134221、20134222是十进制关卡族前缀；它们不是StageConfig中的精确关卡号。原先精确相等匹配不能完成这些战斗目标。当前对不带启动战斗脚本、无特殊场景参数的普通世界目标，按来源前缀匹配实际规范关卡，并保留原有精确匹配及剧情自定义战斗事件路径。

参考March7thHoney-OpenSource固定提交fe00bdbda3c28ca33d01f171566aa35b5ab95083、AGPL-3.0，GameServer/Game/Mission/MissionManager.cs的OnBattleFinish用StageId十进制StartsWith匹配StageWin。本项目独立编写Java实现，没有把参考项目作为运行依赖，也没有导入它的可执行文件。资源固定724b139d8c9c32d12552eb95745a4fee72bfe48b。

新目标在Battle构造完成关卡波次后捕获：玩家、原始主/子任务对象、已接取周期、目标进度、前缀、场景约束与实际Stage对象。只有BattleService确认当前战斗胜利后才能消费；构造后修改目标/关卡、移动楼层、旧轮过期后创建新轮、战斗期间才解锁目标、失败/退出、错战斗或错关卡报告均不借用先前战斗。试用、宇宙、副本、任务Raid和剧情维度不进入新增普通世界前缀路径。带启动战斗脚本的目标保留原有事件与自定义值绑定；曾发现新增匹配提前完成脚本触发子任务，已修正并重新通过原有检查。

四条完整原始图可以自动分配，TakeParam仍为Manual。实际完成前置对话、来源关卡胜利和后续对话后，每轮发放原始Reward231的5000信用点，2100003领取200活跃点并防重。已完成图次日归档后可重新接取；未完成安全图次日仅归档旧记录、不付奖励，新轮独立从零开始。旧战斗不能推进新轮。没有强制完成主任务或跳过后续对话。

新增51项Java检查。首批16项行为断言先失败，目标绑定5项以及场景隔离6项另外先失败，共27项独立行为失败。早期小夹具12项与首批重叠不重复计数；编译错误、场景夹具缺少剧情队伍、超长测试昵称，以及接入期间原有剧情检查失败均不计入新增行为失败。四个关卡族有49/35/7/7个来源变体，合计98个逐个用真实StageExcel和BattleService结算检查；这是关卡族匹配与结算检查，不是客户端技能、伤害或NPC入战验收。

固定126条原始记录/11份来源文件，包括四条主任务、全子任务图与98个关卡；沿用日常目录和活跃度夹具后共175条/23份来源文件。四条图分别经过实际Player文档两次Morphia恢复，进行中和已胜利子任务保持独立状态，恢复后完成原始后续对话才领奖。四条图的胜利前后冻结4.6 GetMissionData字段分别检查进度0/1、子任务Doing/Finish，主任务仍Doing且没有主奖励；这是本机消息调用，未经过KCP客户端。

最终3913项Java、15项Python、151份冻结协议、独立源码构建、Dispatch存储冒烟和最终jar上的68项受控换日日常委托网络检查，以build/dailystage-3913-source-verification.json的passed为准。68项网络沿用原始3000201对话、过期归档、5000信用点/200点及两次正常H2恢复，不能作为四条新增战斗委托的正向网络验收。
