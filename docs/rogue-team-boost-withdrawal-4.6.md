# 4.6 附加战技点与增益条目撤销

附加登记撤销捕获当前链表，从 head 开始按原始登记号查找第一个匹配项。存在位只测试低位 bit 0；登记号保持有符号原始位，不作为数量相减。下一节点为空时直接结束，非空时才要求当前节点 owner；下一节点为该 owner 的 head 时结束。匹配后在最初捕获的链表中移除，不默默接受外来节点。

链表移除先验证 node 属于 list。单节点自环直接清空 head，不要求 previous；其他节点先写 next.previous，再要求 previous 并写 previous.next，需要时前移 head。随后清空 node 的 previous/next/owner，最后 count 减一、version 加一，保留整数回绕。缺失 previous 时已经写入的 next.previous 保留；其他后续失败不回滚已完成的链接写入。

增益条目按最初捕获的数量逆序查找，使用 modifier 引用身份，撤销全部匹配项。条目为值结构快照，子列表实际是 List<GameEntity>，本实现仅清空实体引用，不执行实体销毁。子列表版本先加一，保存旧数量，数量清零，再清空旧有效前缀；零或负数量不要求底层数组。完成后重读当前外层列表，先减少数量，再移动后续条目、清零尾槽，最后增加外层版本。

编译后的显式容器保留零值条目的空 modifier 匹配语义和容量尾部；没有把未知条目解释为已应用的战技点效果。子列表存储缺失、数组越界或外层移动失败时保留已完成的头部写入；逆序处理的成功前缀保留。子列表清空失败后数量已为零，再次撤销可以跳过缺失存储并完成外层移除。
