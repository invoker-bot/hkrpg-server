# 教学结束后的模拟宇宙选世界界面（4.6）

## 现场与原因

用户打开第一世界时只看到奖励预览，进入按钮没有文字，无法继续。2026-11-01 的本机 `Player.log` 两次记录同一错误：`RogueSimulatedEntranceListPanel.bytes:714` 在 `_move_to_index` 对空索引做减法，调用来自 `_move_to_cur_area` 和选世界页初始化。

只读检查 UID 10001 的正式存档：第二次教学探索仍保留区域 100、地图 2、`FINISHED`，已经退出探索，三间房间已清理，未执行普通世界的退出结算请求。原有查询将这份教学记录继续作为当前探索及可选区域发送。该区域的原始 `AreaProgress` 是 0；客户端选世界页按进度 1 起建立可见列表。客户端默认区域查找仍能取得区域 100，而可见列表里没有相应索引，这是与现场堆栈相符的静态原因判断。

本机客户端 Lua 索引 SHA256 为 `619db3bdd4730d92ada44132b7badcdde7d11159df4d2fea10fae36bd8e50346`；完整提取的 `RogueSimulatedEntranceListPanel` 原件及默认选择函数 `RogueUtils.GetDefaultAreaDataToShow`（RVA `0xe056380`）用于交叉核对。r2mcp 连接中断后使用项目现有只读解析器核对，没有运行或修改客户端代码。

另一个独立条件：第一世界原始解锁链 `12001 → 11 / 11007` 要求教学任务 `4030001`、`4030002` 和开拓任务 `1010403`「她等待刀尖已经太久」均已完成。正式存档中两个教学已完成，`1010403` 尚无完成记录。修复界面不代表取消这个关卡前置。

## 修复范围

`Universe46.snapshot` 只在已结束、失败或放弃的教学探索已经返回外部场景时，将对应进度 0 的教学区域从此次可选目录和当前探索投影中移除。不会删除或重置持久化的探索、队伍、祝福、胜利、任务和结算记录；该变更不需要存档迁移。

仍在探索中的教学，包括暂停在外部的探索，继续返回原始地图和恢复信息。仍在教学场景内的结束记录保留原有结算资料。正式世界的结束记录及退出流程不变。第一世界继续使用原始任务条件，未满足条件时返回锁定状态，直接开始也不能绕过校验。

原始区域与解锁规则切片保存在 `src/test/resources/fixtures/rogue-tutorial-catalog-4.6.json`，其中登记完整来源文件的 SHA256，没有改写运营资源。
