# 洛奇桌面资料的整套拾取与任务前置

## 现场和原因

2026-11-04 用户截图中的拾取入口位于主控舱段洛奇旁边。正式服务日志记录了 UID 10001 在该楼层四次请求 `118191`，均返回 `2612 / INTERACT_TYPE_INVALID`；因此请求已经送达服务端。

原始资源定位为 P10001/F10001001/G17/实例300001，物件101030、事件20001507、奖励2000167。固定奖励是《黑塔情诗其一》《黑塔情诗其二》《黑塔情诗其三》（190172、190173、190174）各一件。旧逻辑只接受恰好一本书，导致这套资料被排除。

同时，G17 的 `LoadCondition` 要求主任务2000110完成。该组分类为 Atmosphere，旧分支仅检查 `AtmosphereCondition`，遗漏了阅读物原始的任务条件。只读现场快照显示2000110仍为DOING，故此处也存在提前显示问题；修复不跳过该任务。

## 实现范围

普通固定阅读物现在接受原始奖励表中的一至六种不同书籍，每种必须恰好一件，全部符合现有普通书籍入包规则。特殊脚本、任务物品、非书籍、混合货币和随机掉落仍按原限制拒绝。奖励先整批核对堆叠上限与所需背包空位，再保存一次领取意图、通过正式库存接口投递，最后保存完整收据并更新物件状态。

单本收据原有的 `source/reward/book/granted` 保持兼容；多本收据额外保存排序后的完整 `books` 列表。恢复必须匹配整套书目，单本收据不能假装整套已到账。投递或完成保存中断时保留待对账记录，不自动重发；不宣称跨 Player/GameItem 文档的断电原子事务。

只对普通世界中使用同一公共拾取脚本的 Atmosphere 阅读物组补上原始任务加载、卸载条件。初次场景加载、显式加载、任务刷新和交互资格共用判断；未完成时隐藏，完成后出现，条件撤销时移除并拒绝旧实体编号。其余气氛组与实例玩法保持现有规则。
