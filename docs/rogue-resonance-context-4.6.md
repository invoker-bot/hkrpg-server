# 共鸣上下文查找前段与逐键求值

新增 `RogueResonanceContext46`，在明确绑定的固定数值容器中实现原生查找前段。默认作用域依次查找可用的回调临时容器、额外参数栈顶到父帧、模板和 Modifier；显式作用域 1、2、9 分别只查模板、Modifier、回调临时容器。Ability、实体 custom data 和全局 alias 的后续分支未实现，缺失值不会变成零或落到错误容器。功能继续为 `partial`。

## 原生来源

冻结夹具保存上下文选择器 508324、表达式 VM 70469、`GetDynamicValueByKey` 508325 三个完整 PE 方法，共 9,257 字节。TaskContext 的逐键 provider 方法 509824 另存 103 字节指令范围；它没有完整 PE 入口证明，不称为第四个完整方法。八个元数据字段、模板接口、实际混淆名为 `PFMDDEGLECM` 的数值 provider 接口、原始作用域枚举及两张原生跳表交叉核对。

选择器在作用域 0 或 9 检查当前回调参数；作用域 9 缺失时不继续。作用域 0 随后沿 ExtraParamStack 的父链查键，再查模板；模板作用域不借用其他容器。后续 Modifier 的显式作用域也在缺失时停止。Java 接受调用方预先选出的可用回调容器以及各角色的固定数值 lookup，不负责读取游戏世界参数栈状态、获取接口对象或建立真实角色绑定。

VM 每遇到数值变量引用，按键调用 provider；函数键在单独的函数列表识别。Java `Program.evaluateWithResolver` 保留按引用顺序求值，重复引用再次读取，不先合并变量表或把函数键当作数值。既有 `evaluate(Map)` 继续复制并验证全部显式输入。原生 `GetDynamicValueByKey` 临时替换 alias evaluator 并恢复的路径已保存为来源；本实现只读取固定数值 cell，没有实现该原生 evaluator 或动态 cell provider。

## 任务接入范围

2791 表达式写入新增 `executeInContext`，仍在入口设置生命周期状态、执行魅惑跳过、求值一次后写入明确选择的目标。2855 属性写入通过明确作用域选择变量容器，再读取调用方提供的首目标 CurrentSP。1221 舍入在明确作用域选定容器后执行，并继续只在 setter 返回后设置完成状态。

额外帧列表复制输入，空 lookup 的帧跳过，实际 cell 保持可变；最多 255 帧是项目的有限边界。没有自动创建缺失变量。显式不支持作用域和默认查找后段拒绝执行；入口生命周期状态不证明效果成功。尚未把这些 API 安装到真实战斗状态、网络动作、能力条件或整个能力调度中。
