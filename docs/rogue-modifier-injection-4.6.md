# 4.6 修改器固定数值注入与编码比较

`RogueModifierInjection46` 补入固定数值注入列表的顺序处理。`RogueResonanceVariables46.injectSourceStandard` 安装或替换标准数值根单元，供明确绑定的替换流程调用；未安装真实世界、原生容器工厂或在线修改器实例。

数值编码比较按原件区分低位模式标记：标准值之间比较有符号Int64；扩展值之间去掉标记后比较；混合比较先将标准值算术右移7位，再比较扩展有效值，相等时继续检查标准值低7位余数。裁剪先判断下限，再判断上限；数值相等保留输入编码，倒置范围也保留原件的判断顺序。这些比较和裁剪支持两种编码，变量单元的写入仍仅开放标准值，未扩展到混合算术。

原件声明 `STANDARD_FRACTIONAL_PLACES=32`，标准编码另含一个模式位，因此本工程标准原始值表示中的总位移为33。扩展相关常量是 `EXTENDED_SLIDE=7`、`EXTENDED_TOTAL_SHIFT=26`。没有把总位移33写成原件小数位常量。

新根单元默认上下限为 -6710886399932891135 和 6710886399932891137；这两个扩展边界涵盖所有标准Int64原始值。替换已有固定单元时复制旧上下限，再安装输入值，不按旧范围二次裁剪；后续普通写入仍遵循保留的旧范围。原生初始化器还包含吸附信息、特殊重置标记和其他单元分支，本批未实现这些分支，不将默认边界混同于重置标记。

注入每次通知观察者，包括输入值没有变化时。通知的上一个值为缺席，`Change.previousPresent=false`；既有普通写入通知继续保留其上一个值及 `previousPresent=true`。回调发生在安装后，回调异常保留已经安装的单元；同线程重新进入读取或写入仍访问同一容器。

列表要求明确存在，空列表不读取数值容器，空引用按原件失败入口处理。每项处理都重读当前容器和列表长度，回调追加或缩短列表影响下一次迭代；传入列表本身被捕获，回调替换状态里的初始列表字段不会改用新列表。错误保留此前已经处理的项目。255项/根单元是本工程有限执行保护，不冒称原生列表或字典容量限制；投影容器和扩展原始值保持拒绝。
