# 4.6 虚构叙事教程结算目标

仅在原生 Normal 虚构叙事的实际第二半场完成结算后，推进已接取的单次、无回溯 `ChallengeStorySettleCnt` 目标。支持最终胜利和回合上限结束；普通失败结算的语义仍未核实，不计入此子集。有效结算可以是零星，星数不是教程目标条件。

目标在入战时冻结完整配置与原始脚本，结算时仍需匹配接受状态、任务取消、实际战斗与同一挑战、半场、场景和队伍。第一半场、退出、普通失败、旧协议、晚接取、目标或脚本改变不推进。重复结算与既有历史不会回溯补完。

来源为 TurnBasedGameData `724b139d8c9c32d12552eb95745a4fee72bfe48b` 的父任务 8017101、完整任务配置、全部五个目标与五个原始脚本，共八份 Git blob。原始目标 801710105 完成后，聚合 801710103 开启 801710104；在原始城市楼层完成字面对话才执行 `ChallengeStoryEntrance=1`，并保存动作游标。

23 项行为回归在旧实现上出现四项预期失败（三个合法结算及后续链路），隔离候选全部通过。旧实现测试仅补充空目标快照字段以编译测试，没有结算推进钩子。正式角色、已接取父任务与两个前置完成状态是显式隔离夹具；目标完成、聚合、后续对话、入口值和战斗历史不预写。原始前置接受条件、完整演出、真实游戏 UI、玩家战斗输入与完整伤害运算尚未验收。
