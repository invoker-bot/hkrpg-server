# 4.6 StageParamEntry 参数构造

`RogueResonanceStageParams46` 覆盖原生参数构造器的标准数分支。参数名字为 `#ADF_` 加原始来源下标加一，值直接复制原始有符号定点词，不通过 float 转换或小数重算。从中间下标开始时仍保留原来源编号，不能重新从 `#ADF_1` 编号。

## 原件与 Java 接口

冻结四个完整 PE 方法，共 2,038 字节：508228 创建数组、508229 按数组下标写入、508230 按来源下标追加到具体 list、508231 从零遍历并追加到接口 list。类型槽 `0x937d160` 指向 StageParamEntry（15143），其 Key 在 `+0x10`、FixPoint Value 在 `+0x18`。格式字面量槽 `0x9713190` 为 `#ADF_{0}`，包含前导 `#`。

`create` 对 null 或空来源返回 null；有效来源返回独立条目数组。`assign` 从 startIndex 写到同一目标下标，保留此前和来源范围之后的目标条目；`append` 从 startIndex 读取来源并在目标 list 末尾追加，保留原 list 条目。null/空来源或起始下标不小于来源长度时不读取目标，也不验证未处理的定点词。有效来源的负下标或缺少目标明确失败。

目标过短或 list 添加失败时，此前成功写入的条目保留。项目标准数分支在遇到扩展词时停止，保留此前输出；原生可携带扩展词，此分支仍未开放。有限接口接受最多 255 个来源位置和已匹配 ASCII 参数名，这些是本项目边界，不宣称为原生数组容量限制。

`Entry.key()` 使用既有 StringHash 标准算法。`#ADF_5` 的键是 `-1862642832`，与表达式引用 `ADF_5` 的 `909827949` 不同。此构造器不会自动去掉前缀、添加同名别名、合并上下文或安装能力配置；实际参数来源与整条技能接线继续待完成。

后续已在原始 `StageAbility_612620` 的创建事件字典中匹配两个键之间的显式转交，见[事件参数说明](rogue-resonance-event-params-4.6.md)。实际参数查询与战斗接线仍待完成；此构造器本身继续只保留原始名字。
