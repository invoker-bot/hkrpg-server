# 4.6 主任务与普通任务联动

固定4.6资源中453项Quest完成规则使用FinishMission，其中330项QuestType=1、123项周期类型3。原实现没有从实际主任务完成记录推进这些普通任务，教程主任务1000201结束后4000001仍进行，依赖它的普通任务也不能解锁。MainMissionQuestCounts读取实际主任务完成数量，按原始ListContain列表和Progress门槛推进普通类型1/4；完成保存并同步后刷新依赖解锁，无须领取主任务奖励或等待下一次任务查询。

目标Quest及FinishWay必须属于当前目录且编号匹配，原始形状须为FinishMission/ListContain，列表为最多256个不同正编号，目标为正且不超过列表长度，无附加整数、字符串或道具参数。所有来源必须有编号匹配的MainMissionExcel，来源记录须满足有效存档键/编号、FINISHED/CLAIMING/CLOSED、进度1、正完成时间且未取消。损坏来源不计数，其他正常来源仍计数；不降低已经观察到的进度。周期/日常域不读取普通questStates代替其周期记录，未知形状与缺失定义保持待办。

MissionManager.refresh每轮观察普通任务完成，但仅在有效来源实际完成后刷新任务解锁。没有来源完成的剧情查询不会顺带创建无关普通任务。QuestCompletionRecords同时收紧FinishQuest解锁证明：依赖来源需有普通任务定义、编号匹配的FinishWay、达到其自身目标的明确完成记录和正时间，空阶段、错误编号/进度/时间及来源缺失不开放后续任务。没有自动修补运营存档。
