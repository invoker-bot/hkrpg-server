# 经典宇宙各世界 Boss 绑定

共享 Boss 房间的原始 `GroupWithContent` 指向固定怪物组。全局房间池混用不同世界的场景，使实际 Boss 与所在世界不对应；九个世界的入口回归中八项真实失败。新增可选 `data/RogueBossGen.json`，为九个经典世界的 32 个原始区域配置对应怪物组 11901 至 19901。配置是本服明确的世界内容绑定规则，不修改原始房间表或借用其他客户端版本的字段。

新局创建前核对配置、原始怪物组权重、NPC、关卡类型和完整波次资源，以及只有一个战斗内容组的 Boss 房间。实际新局保存区域、地图、内容组和关卡签名，再创建场景。普通房间及内容为零的辅助组保持原始来源；Boss 场景沿用原始放置物件和组身份，实际 NPC、事件关卡与波次来自该世界原始组。

计划和“已计划”标志同存 Player，怪物选择继续使用已有每局收据。配置改动不重绑已经开始的探索。权重、怪物映射、关卡配置或实际波次发生变化，计划缺失、签名损坏、归属不符或目录消失时，不生成另一世界的怪物，也不回退到旧的算术选取。旧存档没有这两个新字段时保留已保存的原始房间内容；没有补造旧局的世界选择。

固定来源为 TurnBasedGameData `724b139d8c9c32d12552eb95745a4fee72bfe48b`，十一份完整来源文件 SHA256 单独核对。夹具保留 85 条完整原始记录，含 32 区域、九组怪物/映射/关卡/NPC、十二条波次怪物，以及共享房间 222713、入口、位面、楼层和场景组。实现使用自有 Java，未导入参考项目代码。原始关卡存在基础与变体怪物 ID；直接使用该世界原始组和波次，不将预览 ID 强行替换进战斗名单。

新增 64 项 Java 回归覆盖 32 个区域、九种缺失/坏资源、八种损坏运营配置、十种保存计划或资源损坏、旧格式、可选文件缺失、安装保留、JSON 重载和真实 Player 两次 Morphia 重读。早期测试类的非静态内部类映射错误已修正，不计入行为先失败。

`scripts/smoke-rogue-world-bosses.py` 使用独立标记的 `build/smoke` 目录。九个首次难度区域仅在隔离副本中将解锁设为零，并明确把共享 Boss 房 222713 分配到首站；原始地图、怪物组、NPC、关卡、波次和积分表不改，Boss 配置由生产安装器实际补入。252 次固定 4.6 描述符的 UDP/KCP 请求验证九个独立 UID 的入场、同进程重连、重启后实际入战、正式胜利报告、场景移除、重复报告拒绝、离开及放弃结算，再次重启读取保存结果。九场关卡全部核对原始完整波次，九次重复报告被拒绝，九次积分通知；三次正常 stop 和三份只读 H2 矩阵检查共核对 27 份玩家记录。2,258 份输入资源前后完整字节 SHA256 不变。

矩阵探针没有走完各世界原始路线，也没有领取首次通关奖励。第一、第二世界的实际战斗掉落响应各为 150 信用点，其余七个为零；钱包与实际响应一致，重连和停服恢复不重复到账。后续 [Boss 固定等级](rogue-boss-levels-4.6.md) 已补齐全部 32 区域的本服统一等级策略，并增加实际波次、提前击杀收据和 H2 检查。完整难度缩放、Boss 机制与关卡能力消费、全部客户端战斗输入回放、官方前置、事件房、官方随机地图、游戏 UI 和断电原子性仍未完成或验收。全量构建、独立源码构建及最终 jar 的同产物复核以 build 认证报告为准，整体状态为部分支持。
