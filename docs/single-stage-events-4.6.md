# 4.6 原始单事件难度集合

本批将普通场景的 source2 支持从 20003011 扩展到全部 28 个已核对的单事件行。每行 ID 等于唯一 EventIDs 成员，使用既有原生命令和字段；生成协议、命令号及 4.2 基线不改。14 个多事件行的 owner/alias 更新关系仍未核实，继续拒绝更新。

`src/test/resources/fixtures/single-stage-events-4.6.json` 保存 TurnBasedGameData 固定提交 `724b139d8c9c32d12552eb95745a4fee72bfe48b` 的三份完整文件证明及 420 条原始记录：28 条 DifficultyAdjustmentStage、196 条 PlaneEvent 和 196 条 StageConfig。每个事件均有世界 0 至 6 的原始 Mainline 关卡。没有复制其他项目的运行代码，也没有修改已安装资源。

偏好按事件分别保存，查询按事件编号排序，只返回已选择项。未选择仍为默认，有效世界为实际世界；简单为实际世界减一，世界零保持零。现有 20003011 的来源指纹和存档格式兼容。一个已保存选择损坏或来源变化时整份查询拒绝，不发布部分有效项。重复选择不多次保存，保存失败回退该事件原值。另一 owner 重复引用该事件时拒绝建立身份。

普通入战沿用不可变场景计划，核对玩家、场景对象、plane/floor/entry、实际和有效世界、原始 Stage 及波次。事件 20321050 同时用于 43306 副本：有活动副本时使用副本已冻结的 source1 难度，普通事件偏好不能覆盖。其他现有实例、宇宙、试用、跑酷和故事线模式保留各自入口规则。

新增 565 项 Java 检查包含 336 种明确选择、196 种未选择默认关卡、六种副本优先级、多偏好隔离/排序、14 个分组拒绝、重复别名、来源变化、旧指纹兼容和实际 Player/Morphia 四种完整集合各两次恢复。扩展前 540 项中 332 项选择相关断言真实先失败，其余默认对照通过；随后输入防护阶段四项中两项复现新增别名读取的异常，单独记录为本批实现修正，不计成两个旧玩法缺口。

`scripts/smoke-stage-event-difficulty.py --single-events` 计划在同一隔离账号完成 28 个未选择、28 个显式默认和 28 个简单战斗，正常关服后从 H2 恢复全部偏好并重新进行 28 个简单战斗。每场核对原始怪物、有效世界、活动战斗查询、重复入口拒绝、战斗中改选拒绝、错误结果身份拒绝及 QUIT 防重。预计 1,356 次请求、112 场事件战斗、三次正常关服和两次同 UID 进程重启；正式世界一仅离线设置一次，正式队伍保持不变。未结束的运行不能计完成，最终结果以同一产物 SHA 的认证报告为准。

普通场景、正式角色和进入前置是明确隔离夹具。原始资源中未找到这些事件编号的地图组直接放置，不能据此声称 NPC 入口已完成。原始剧情任务的 StageWin 族编号与 TriggerBattle 编号分别保留，完整脚本、机制、战斗输入、全部活动/宇宙、客户端按钮与演出、进行中战斗持久化及断电原子性仍待完成。
