# 4.6 共鸣整数转换、余数与位运算

本批补入 `int`、`mod`、`leftshift`、`rightshift`、`and`、`or`、`xor` 的有限标准数分支及后缀调用。十五个原生注册函数现在均有明确的有限数值实现；这不表示扩展编码、实际共鸣参数、任务调度和战斗效果已经完整。原有协议、命令号、版本与生成类不变。

## 原生来源与行为

七个回调索引为 74382、74386、74390–74394。连同 Approximately 68530 和 FixPoint 初始化器 68417，共九个完整 PE 方法、4,200 字节；Add/Sub 的标准路径与舍入中间编码共 303 字节片段单独记录，没有冒充完整 helper。实际 float32 系数表八字节与 ONE 初始化对十六字节也核对。名称/键/方法身份沿用冻结的原生十五函数注册表。

int 先按最近偶数舍入，再调用 Approximately 检查差值绝对值是否**严格小于**初始化器直接写入的标准原字 `0x218c`（8588）。近似整数返回该舍入原字；其他输入经 signed64→float32、乘实际 `2^-33` 系数，再用向零截断转换整数。Java 保留 float32 精度，不用 double 或纯整数截断替换：精确整数 16,777,217 可直接保留，但 16,777,217.25 经 float32 后返回 16,777,218。接近负端点且差值小于阈值可返回标准 `Long.MIN_VALUE`；需要扩展编码的最终结果拒绝。

mod 标准分支直接取原字余数。有符号大数走 `cqo/idiv`，两个非负低 32 位数走无符号 `div`，有限 Java 在这些标准输入上均保留被除数的余数符号。零除数和扩展输入拒绝，不模拟原生异常退出。

移位先按最近偶数舍入首参数，第二参数直接按标准原字右移 33 位，即向下取整。实际运算为 32 位 `shl/sar`，位数按低五位折叠；负位数和超过 31 的位数不会改成饱和或逻辑右移。and/or/xor 则将每个参数按最近偶数舍入，再依原顺序折叠，单项也进行舍入。

标准正端点附近的首参数可能先经 Add 进入扩展的舍入中间编码，再被移位/位运算提取整数；额外 178 字节 Add 路径明确匹配这个转换。因此最终结果回到标准范围时可以返回，例如正端点向右移 30 位得到 ONE。这里没有开放一般扩展输入或最终扩展结果；最终整数绝对值达到 `1<<30` 时，位运算/float 回退继续拒绝。

有限入口要求 int 恰好一项、mod/移位恰好两项，位运算 1–255 项。原生前四个回调忽略额外参数，当前明确拒绝。后缀编译、参数源顺序、一次求值、失败短路、callee 隔离及原有栈/树深限制沿用多参数批次。
