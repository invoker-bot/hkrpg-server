# 4.6 日常模拟宇宙通关目标

原始目标2100150位于日常池类型9，QuestType5、AutoUnlock，完成规则为`RogueFinishCnt`、`NoPara`、进度1，无整数/文本/列表筛选；奖励103005给Item23×500。现选择这一明确规则形状，并在执行时重新核对未知参数。

推进事件在`UniverseManager.finishRun`确认成功结局、转为FINISHED且`recordRogueWin`首次记录该次通关后触发。普通胜利、清理中间房、剩余内容组怪物、未知末房定义、失败、退出和放弃不能代替通关。既有绑定战斗检查保留；查询结算和完成战斗重放不触发新事件。每日4点后的真实新通关计入当天，旧完成记录不会靠查询完成次日目标。

新增`daily-rogue-finish-4.6.json`记录四份原始池/任务/条件/奖励，源提交`724b139d8c9c32d12552eb95745a4fee72bfe48b`，逐条保留源路径、文件和Git blob SHA。日常记录不改；测试复用现有`UniverseCombatFragmentsTest`的构造战斗/组/末房地图，怪物波次为空，不代表原始完整世界通关。

`DailyRogueFinishTest`20项检查覆盖原始选择、末房事件、原始500活跃度一次领取、失败/退出、放弃、旧运行、剩余怪物/非末房、并发/重复、次日、JSON恢复、六类未知规则变体和缺失站点。先保存一项未选中目标的真实失败，再接入选择；余下20项中五项真实复现末房已完成但日常未推进，随后接入事件。共六项先失败，编译或夹具错误不计入。

这些新通关联动验证直接调用当前绑定的真实Battle/UniverseManager，实现保存为测试替身，JSON恢复也不等同Morphia/H2。新增日常物件网络脚本验证的是自动目标及破坏目标，不能据此宣布宇宙通关目标已通过KCP、原始完整世界或真实游戏UI。既有运行历史、结果、每日状态沿用玩家保存顺序，不声称断电跨功能原子性。

日常池仍有战斗统计、委托、合成、升级等条件待接；完整剧情脚本、宇宙分支及活动小游戏仍待继续完成。协议冻结文件、生成类、版本常量未修改。
