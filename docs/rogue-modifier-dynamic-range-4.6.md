# 4.6 数值范围事件的有限执行

修改器共享既有替换状态。监听字典按完整变量哈希和作用域选取列表；缺少字典或键时不执行、不预先校验未知数值。找到键后压入修改器、哈希和动态值类型3的临时帧；旧值存在时使用既有标准定点减法，没有旧值时变化量为0。回调成功后重新读取当前游戏模式和帧列表，弹出当前末项；异常保留已经执行的前缀，不添加自动回滚。

范围组按当前列表数量逐项执行，可观察回调期间的追加、清空与元素变化。先读取最小值并求值，再重新读取配置和上下文求最大值，即使当前值低于最小值也计算最大值。最小值包含端点，最大值按当前MaxInclusive决定。原始配置允许反向区间，不自动交换边界。常量仍要求当前上下文；表达式使用已经实现的明确数值查找。

进入或退出范围先更新状态，再执行对应序列。状态未变化且仍在范围内，只有旧值存在且数值不同，或TriggerClampedChange开启并且传入变化量非零，才执行变化序列。同值通知和注入的旧值缺席分别处理。重入上限每次组调用捕获一次，使用配置低位的有符号字节；负值跳过限制，当前计数等于上限仍允许进入。三个回调计数独立，递增、回调、正常返回后递减，保留字节回绕与回调修改后的当前值。

多个变化监听共用首次创建的参数，实际差值与传入变化量分别写入参数0/1；额外上下文和额外命中数量明确绑定。参数在重入判定之前取得和登记，受限跳过也在正常结尾回收。回调修改后的参数不逐项重置。正常结束重新读取当前上下文和参数池，移除当前末项并回收；嵌套调用恢复外层参数。这里实现的是工程的明确Java参数池，未冒称原生对象工厂、完整原生池或通用任务执行器。
