# GM 隐藏与限定来源物品快捷清单

「物品快捷清单」是独立的 GM 页面，按角色、光锥、角色时装、头像、头像框、聊天气泡、手机主题、手机壳、开拓者装扮、宠物、帕姆服装、个人名片、唱片、勋章、任务物品、材料、消耗品及其他物品分类。类型选择框显示该类数量；可进一步按收录依据筛选，并搜索中文名称、角色、类型、物品 ID 或获取来源。支持分页、刷新和查看完整收录依据。

服饰分在「角色时装」「开拓者装扮」「帕姆服装」三类。搜索「服饰」「服装」「衣服」可同时找到这三类；「皮肤」匹配角色时装和帕姆服装；也可直接搜索「开拓者装扮」等类型名称。角色时装详情依据已加载的 `AvatarSkin` 绑定显示对应角色和 ID，例如「对应角色：三月七 #1001」，可按角色名称搜索；没有绑定资源时不虚构所属角色。类型和收录依据筛选仍与搜索同时生效。

也可按商店名称搜索已收录的条目，例如「星尘之礼」。清单依据实际加载的固定商品关系补充商店名称、商店 ID 和商品 ID，即使 `ItemComeFrom` 缺少该来源也能找到。商店目录关联只补充查询依据，不据此给普通商品增加隐藏或限定标签；商品是否当前上架继续以「商店管理」为准。轮换商品的候选关系未在本轮补推断。

选择在线玩家后，可点击列表的「发放 1 份」，或在详情中调整数量、角色/光锥等级与星魂/叠影后预览发放。每次执行都明确显示目标 UID、物品和数量，使用原有 Cookie/CSRF、持久操作记录及请求编号去重。没有在线玩家或资源不支持时，发放按钮禁用；查看与搜索仍可使用。普通「资源发放」页面保持原有功能。

## 收录规则与来源

清单运行时读取当前已加载的物品定义及资源表，不依赖网络、参考仓库或人工输入的一组稀有物品编号，也不写回运营资源：

- **隐藏/可见性受限**：物品资源未设置 `isVisible=true`，或 `PhoneThemeConfig` 等声明 `UnlockedOnly`。未设置可见性只描述资源事实，不宣称该物品在所有游戏界面都隐藏；角色卡与虚拟余额常规省略该字段，不因此标为隐藏。
- **限定/排期来源**：`ItemComeFrom` 的中文来源明确包含限时、限定、联动或无名客/无名勋礼；或外观显示规则为 `InSchedule`。
- **活动来源**：来源文字包含活动，或显示规则为 `AfterStart`。活动来源不自动等同于已绝版。
- **活动跃迁**：沿用本项目已有、绑定官方公告的历史卡池档案，收录其中五星 UP 且不在内置常驻目录的角色/光锥；详情保留相应资源版本。这是固定档案与内置目录的分类，不以运营临时改过的卡池推断官方永久资格。
- **外观收藏**：所有已加载且具有唯一收藏语义的外观、头像、名片、宠物、唱片和勋章，不把所有收藏品都标成限定。

类型、标签与收录文字独立展示。同一物品仅一条记录，可有多个标签和来源；显示的中文排版标签会清理。未被加载、仅用于展示或缺少正式物品定义的内容不生成虚构的可发放条目。本轮不是官方全部绝版物品考据或所有游戏数据的完整分类。

资源读取为 `ItemExcel.isVisible`、`ExcelOutput/ItemComeFrom.json`、`TextMap/TextMapCHS.json`，以及聊天气泡、手机主题、手机壳和个人名片的显示条件表。历史卡池与常驻目录分别来自 JAR 内已有的 `gm/banner-history.json` 和 `defaults/Banners.json`。这些资源沿用已有来源与许可证；本轮没有导入新的第三方代码或运行依赖。服务首次查询后缓存，资源改动需重启重新索引。

## 发放与异常边界

读取接口为同源会话的 `GET /gm/api/item-shortcuts`，支持 `type`、`tag`、`q`、`offset`、`limit`（默认 30，1–100），返回类型数量、总数及条目。写入仍使用 `POST /gm/api/operate`，`action=shortcut-grant`，字段为 `uid`、`itemId`、`amount`、`level`、`rank` 和原请求 UUID。

服务端重新验证当前清单成员、实际资源发放能力、整批数量、唯一所有权、背包容量与堆叠上限，再复用已有实际发放逻辑。收藏品和角色每次 1 件，已拥有收藏品拒绝重复发放；装备最多 100 件，普通堆叠物品最多为资源上限且不超过 100 万。参数及目标变化继续按既有 GM 边界校验。未支持的条目保留查询及原因，通过直接构造 HTTP 请求也不能绕过限制。帕姆服装补发已有 4.6 解锁通知。

实测发现旧头像框发放在写入所有权集合后，发送 `BoardDataSync.unlocked_head_icon_frame_id_list` 时会遇到 4.6 未映射字段。没有猜测新协议字段或静默丢弃通知；本轮将头像框明确标为仅供查询，快捷发放在任何所有权修改前拒绝。已有普通 GM 与其他入口的历史行为不由本功能冒充修复。未知子类型也仅供查询。

钱包、普通道具与解锁集合仍由现有存储机制保存，不提供跨文档断电原子性。异常操作继续记录为待核对，不自动重放不确定的发放。
