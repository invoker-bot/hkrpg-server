# 4.6 奇物与骰子自动强化计数

固定4.6资源中的万象无常骰20声明最多强化两条祝福。实际取得时先准备完整、唯一、版本1的一级及二级定义和对应MazeBuff，只在实际一级到二级变化时增加已确认强化次数。已有二级祝福、未知或重复等级定义、新取得的一级祝福及候选预览不计数。实际批次与剩余计数空间整批预检；损坏计数或整数空间不足时，奇物、祝福、余额和待选菜单均不提交。

这批将实际奇物20升级接到已有4092314/4092315原始10/200目标。将自动升级纳入同一计数是本项目对RogueBuffEnhance的明确实现规则，尚未以官方UI验证该条件如何区分付费与自动来源。奖励仍使用原始5/10星琼、4000001前置和既有领取收据，不改阈值，不从旧持有状态补造历史。

骰子奇物21的准备只更新玩家状态的深复制。计划冻结原玩家计数对象及数值；真实提交先验证当前探索、定义、图鉴、祝福历史和计数没有变化，再合并实际替换、祝福升级与计数增量。过期或并发重复计划不能覆盖后来完成的强化。提交并保存后刷新任务与原生通知；只取得新祝福的替换不计为强化。

24项新增Java检查覆盖实际两条/一条/零条升级、原始10/200阈值与合计15星琼、重复/并发、一级赠送排除、五次预览不变、骰子实际提交与冻结计数、损坏和溢出计数、缺失/重复/另一版本资源、付费历史继续累加以及两组真实Player Morphia二次重读。首批15项中12项为真实行为先失败。固定夹具保存34条原始记录、十二份文件及路径、提交和原件SHA；单一骰子替换池是明确领域夹具。
