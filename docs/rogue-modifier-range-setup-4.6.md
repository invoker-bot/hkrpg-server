# 4.6 数值范围回调序列的创建

范围定义明确持有既有数值区间配置和进入、退出、变化三组子任务工厂。缺省数组不创建回调、不读取上下文；空数组仍创建独立的READY序列。三组依次创建，每次从当前世界读取上下文并保存在该序列中，再创建子任务；上下文可以明确为空。工厂获得正在创建的父序列，能够读取其READY状态和捕获上下文。创建未完成时，执行、改状态、访问子任务、重置与释放操作保持关闭，避免把这一有限构造适配器冒称完整原生任务工厂。

每个定义进入工厂完成后再读取当前退出字段，退出完成后再读取变化字段。已经捕获的数组保持不变，但其后续元素按执行时内容读取；前一个定义创建期间修改输入数组的下一个元素，也会影响后续定义。区间配置保留原对象身份。三组成功创建后，初始化三个字节计数为零、范围状态为false，再检查目标列表并追加。失败保留已经追加的定义及已执行工厂的副作用，不追加当前未完成范围项。

生成的序列复用RogueTaskSequence46现有调度器，明确关闭演出即时完成开关。子任务列表固定、按原顺序执行；等待任务接受实际时间增量，成功与失败继续使用既有状态处理。序列同时实现修改器计数接口。实际范围变化能执行新创建的进入序列，销毁退出能执行新创建的退出序列，修改器完成处理能重置子任务并冲减执行计数。没有把执行回调自动视为已完成，也没有增加等待任务的固定完成逻辑。

来源核对_SetupRangeCallbackList完整PE方法727字节、五类字段、一个子任务工厂方法身份，以及范围项和序列的两个实际构造类型槽。序列类型54769确认为既有任务调度器同一类型，状态类型54773和READY值0x7777独立核对。三个配置任务数组偏移40/48/56，范围项进入/退出/变化序列偏移32/24/40；深度48/49/50、范围状态51。完整原始配置工厂的类型分派、任务前后链接和父接口尚未完成，这里的工厂由调用方明确提供。

255个范围项、512个子任务与未完成构造操作关闭属于工程的明确保护；没有宣称它们是原生容器限制。空定义数组在读取世界、状态和目标前返回；非空定义要求明确状态、世界和编译后的范围配置。目标列表验证发生在三个工厂完成后，工厂能够清理列表容量。
