# 4.6 弱点重置、默认数组、复制和特殊列表

普通重置按四类枚举和独立跳转表分派，逐槽仅对占用项执行 `mask &= ~damageMask`，保留占用位及未占用槽的原值。槽被清成零仍保持占用，覆盖类别不会因此回退默认弱点。完成遍历后调用同一类别聚合与活动刷新；占用数组缺失或越界时保留已完成的槽写入，不提前刷新掩码。

默认弱点入口接收实际 AttackDamageType 数组，以原始有符号位做按位并集；空引用对应零值。计算成功后先写默认掩码，再调用覆盖类别和活动刷新。工程只接入已明确的数组入口，未声称所有 IList 实现的动态调用和 IFix 路径均已实现。

复制始终先复制覆盖聚合和默认掩码，再复制覆盖数组、占用数组并刷新；随后复制附加类别，最后按两个独立布尔位选择保护和秘密类别。低位 bit 0 控制保护，第二字节 bit 0 控制秘密。源数组较短或等长时复用目标引用并清零全部尾部；源数组较长时发布独立的完整副本。源或目标数组缺失时明确失败，不自动调用初始工厂。

复制末尾先置脏、清零活动掩码，再清空当前视图，清零全部掩码，调用活动刷新；活动刷新会再次清空视图。目标 owner、通知开关和特殊列表保留。任何失败都保留原件时序下已经完成的数组、掩码或脏标记写入；通知失败不会清除脏标记。

特殊事件独立维护 List<MonsterWeaknessSpecialType>：启用时已有项不重复添加；禁用时仅移除首个匹配项。Contains 完成后重新读取当前列表和事件类型再添加或移除，不触发普通弱点掩码刷新。Java 状态新增显式特殊列表字段，默认保持空引用，工厂未完成时不擅自安装默认数据。
