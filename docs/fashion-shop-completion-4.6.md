## 验证边界

回归先复现九件物品缺少商品，以及默认或已选帕姆服装在物品记录为空时可能被重复收费；新增测试检查商品对应、售价、限购、资源缺失、编号冲突、已有商品和整批失败。客户端隔离测试检查 903 条旧商品不变、9 条新商品、冲突拒绝、运行中保护、备份和重复安装。自动验证不能证明真实游戏商店界面、图片或穿戴演出，须由用户在客户端确认。

在隔离源码快照运行 `scripts/build.ps1 -TestForks 4 -RerunTests`，20,357 项 Java 测试通过；客户端补丁两组共 20 项检查通过。源码构建产物的完整商店夹具完成 84 次原生请求及两次正常停服。以实际常驻服务为基线的候选包保留 24,051 个无关条目不变，54 项相关 Java 回归通过。对候选包运行 `scripts/smoke-shop-purchases.py --fashion-only`，用隔离账号完成 32 次原生请求，检查九件商品的查询、购买、扣费、重复购买拒绝、饰品和帕姆服装使用，以及同一账号正常重启后的余额、背包、穿戴和限购记录；没有使用正式玩家账号。

实际常驻服务与当前源码在旧书籍礼包处理上存在差异：对候选包运行全商店夹具时，原商品 301003 返回礼包物品，而源码夹具期望直接返回章节。本次保留常驻服务原有行为，故候选包仅执行时装专项验收；这不代表该旧礼包差异已经修复。

客户端数据已在游戏退出后更新，原索引备份位于 `.local/client-patches/fashion-shop-20261115-backup/`；原有 Lua 补丁及启动器清单校验通过。客户端实际显示仍待验收。
