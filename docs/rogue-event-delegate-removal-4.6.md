# 4.6 事件多播委托撤回

Java 21 `RogueEventDelegateRemoval46` 补入普通 Delegate.Remove、基类 RemoveImpl、多播 RemoveImpl 与 LastIndexOf 的控制顺序。复用已有 Callback 与普通委托比较；Callback.methodCodeTarget 改为 Object，因为来源中的克隆将该字段指向新委托自身，基类销毁仍写同一修饰器，没有复制修饰器状态。

公共入口 source 为空直接返回空，value 为空返回 source；其后先查 source 类型，再查 value 类型，以同一明确类型对象进行身份比较，类型不同拒绝，匹配则调用明确虚方法。基类 RemoveImpl 使用虚 Equals，匹配返回空，否则保留原委托。

多播接收者/值数组引用先捕获。单委托对单委托调用实际已有多播相等；单委托对多播值按捕获数组从头寻找，相等便返回空。双方多播时先对捕获数组调用明确数组 Equals；同一数组直接返回空，其余重新读取当前两个数组进行子段查询。等长子段从 source 元素调用虚 Equals，较短子段从 value 元素调用，候选位置从尾部向前，保持来源不同的调用方向。两空数组索引为 0，非空 source 对空的较短 value 保留边界失败，缺失投影拒绝。

多播接收者删除单项使用明确数组 LastIndexOf 绑定，从末端寻找。未命中返回同一委托；命中后重新读取当前数组，长度 <=1 保留来源状态错误，长度 2 返回原有另一个委托，其他情况创建新的多播包装。删除匹配子段总是创建包装，即便只剩一项或空数组；不擅自折叠为单委托或空引用。

克隆分配完成后重新读取源 target/method，写入新委托；methodCodeTarget 写新委托自身，invokePointer 与 extra_arg 投影拷贝源 extra_arg。没有复制源 method_ptr 或 DelegateData。再重读当前数组长度，分配并先发布新的 delegates 数组，执行前段复制。回调可修改源、值和目的数组；后段重新读取值数组（多项）、源数组与结果数组。失败保留已经写入的克隆字段、数组与前段，不回滚或继续后段。有限遍历最多 255 项。
