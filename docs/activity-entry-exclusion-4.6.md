# 宇宙、活动与剧情的入口占用

角色已有钟表剧本、音游、单独保存的跑酷局或旧副本实例时，宇宙新局和暂停局恢复返回 ROGUE_STATUS_NOT_MATCH。已有钟表时，跑酷关卡、跑酷场地和任务副本返回 REQ_PARA_INVALID。已有钟表、音游或单独保存的跑酷局时，剧情分支的预查询与实际切换均拒绝，切换返回 SYSTEM_BUSY。已有剧情分支、尚未完成的剧情返回转换、跑酷局或旧副本实例时，钟表开始返回 SYSTEM_BUSY；音游同时检查钟表、宇宙内部、剧情分支、未完成转换、跑酷局及旧副本实例，返回 MUSIC_LOCKED。

跑酷关卡也拦截剧情分支、未完成转换和旧副本实例；跑酷场地拦截旧副本实例。

检查发生在占用新玩法、冻结奖励、保存返回地点或替换队伍之前；请求失败保留原有两种玩法的保存状态、位置、场景、正式队伍和试用角色。正常退出占用玩法后仍可进入目标玩法。暂停宇宙局可保留在存档里；仅在它实际占用宇宙场景时拦截音游，不删除暂停记录。历史存档的重叠占用由退出已有玩法解除，本批不强制改写或清空运营存档。

28 项新增 Java 行为回归覆盖原生宇宙新局/恢复、原生跑酷关卡/场地/副本、音游和钟表入口以及实际剧情场景与试用队伍切换。修复前 28 个断言失败。测试阶段曾将构建了房间但尚未置为 inside 的宇宙夹具误称为实际占用；修正夹具后重新取得失败基线。扩展时还曾把跑酷用例误设为音游状态，修正为独立跑酷快照后重新取得 28 项失败基线；不将夹具调整计为生产故障。释放音游、跑酷、旧实例和部分剧情测试中的钟表占用使用域状态夹具；宇宙、跑酷正向路径与原生钟表退出另有实际管理器回归。测试场景、角色和部分目录是隔离夹具，不代表这些官方玩法的全内容。
