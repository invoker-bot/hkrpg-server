# 4.6 修改器替换顺序与延迟能力

`RogueModifierReplace46` 补入明确状态与绑定下的普通替换顺序，并复用数值绑定、叠加和寿命状态。范围包括最大层数覆盖存在性、层叠新增量、临时覆盖数据释放、强制层数/立即寿命标志、序列期间延迟能力更新和基础注入顺序；实际覆盖查询、列表安装、上下文/替换虚调用和在线实例仍待完成。

## 替换顺序

先查询临时数值覆盖，再检查输入参数。参数的最大层数覆盖是偏移108的 `Nullable<Int32>`，偏移112读取其存在标志，不是独立布尔字段。有值时调用明确计算、写入 `BaseMaxLayer`，然后无条件通知类型2；即使新旧值相同也通知。无值跳过这个计算和通知。

随后计算并写入 `LayerAddWhenStack`，临时覆盖对象非空时才释放。释放在强制层数、立即寿命标志和基础替换之前；任一步骤异常保留已有写入，中断剩余步骤，不在异常路径补做释放。强制层数复制可空值，不立即改动当前层数。立即寿命标志为输入布尔值或当时的行为标记7，输入为真时不再查询标记。

基础替换读取 `_ExecutingSequenceCount`，偏移152的字段是执行计数，不是模式枚举。计数非零把传入能力写入 `_DelayReplaceAbility`，暂不改动当前上下文；计数为零要求明确任务上下文，调用能力更新绑定和后续虚调用绑定。传入能力可以为空；延迟写入空值会覆盖此前的延迟能力。此体没有实现执行计数归零后的刷新。

接着要求基础参数存在。数值注入列表非空时先赋给 `InitDynamicFloatInjections` 再调用设置；字符串列表随后赋给 `InitDynamicStringsInjections` 并设置。空列表对象仍进入对应设置绑定，缺失列表保留既有字段。最后调用明确的替换后虚调用绑定。槽位的具体实现未被视为已经安装的事件或脚本分发。

回调可以改变稍后读取的参数、执行计数或状态，后续步骤读取这些当前值。层数覆盖、临时数据释放和基础参数缺失仍保持各自原件顺序，没有提前把全部输入预验证或失败时回滚。

只读核对4个完整PE方法共1,543字节、5类字段和4项泛型参数。两组基础注入字段为 `List<GODJKFFNCNI>` 与 `List<CFJJFFMMEAF>`；前者保存Int32键和字符串，后者保存 `StringHash` 与 `FixPoint` 原始值，不把它们当成可空整数或动态表达式对象。最大层数覆盖和强制层数才是 `Nullable<Int32>`。
