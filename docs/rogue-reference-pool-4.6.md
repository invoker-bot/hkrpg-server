# 4.6 普通引用对象池

本批将 `ReferenceCollection` 的普通领取/回收、类型集合查找、共享包装器的类型路由，补入 Java 21 的 `RogueReferencePool46`。仅使用已固定本机 4.6 客户端进行只读静态核对，不执行客户端或引用项目二进制，不改协议、版本、资源和运营数据。运行时继续维持 `rogue: partial`。

## 已实现与来源顺序

- 集合构造在没有容量属性时使用 16；显式属性保留零和正容量。保存引用数组、数量零、类型、扩展接口标志。属性解析及类型反射由显式 Type 绑定提供。
- 领取复用最后一个有效槽，先减数量，再检索/检查声明类型，随后按当前数组和当前数量清尾槽；扩展对象最后执行 `OnAlloc`。空槽在普通池可返回 null，扩展池会在清尾后拒绝。类型或索引错误保留已减数量，不回推对象。
- 无可复用对象时，执行显式分配，按原件的标志位 2 与参数数零选择首个方法再调用初始化。这里保留原始位条件，不擅自将其称作公开构造器。没有匹配项时，普通池返回 null，扩展池失败；方法列表缺失或超过 255 项是本项目有限边界，不模拟一般反射。
- 回收先调用扩展 `OnRecycle`，再调用普通 `Clear`。两者成功后才读取当前严格检查开关、数量和数组；严格检查按对象身份拒绝有效前缀中的重复对象。失败时清空和回调效果仍保留。
- 数组不足时按当前数量乘二扩容，复制原数组前缀；不为空数组添加未经来源证明的默认四槽。数量先增加，再检查数组元素兼容性、无符号下标并存储；越界和兼容性失败保留已发布数量/扩容结果。
- 声明类型与对象实际类一致时使用显式类型池；不一致时按实际类查找集合。集合未存在才构造，成功后重读当前映射再登记；已有值、包含 null、构造失败和登记冲突均有回归。这里只实现通常 Class/Map 的有限投影，未安装原生 RuntimeTypeHandle 比较器或一般 Dictionary 运行时。
- `RogueEventPayload46.create` 抽出可作用于已分配对象的初始化入口，原有构造顺序保持。联合回归真实调用该构造入口、该 Clear 和已有离场尾部，覆盖领取、226/228 或 227/229 分发、清空、入池及再次复用。分发失败不通过 finally 自动回收，Clear 失败不入池。

## 原件与验证

冻结来源为 `src/test/resources/fixtures/rogue-reference-pool-4.6.json`：3 个有 PE 异常目录完整边界的方法 1,357 字节，4 个完整辅助函数 1,804 字节，1 个辅助静态初始化函数 265 字节；严格检查 getter/setter 合计 15 字节仅列为注册叶方法至 ret 的片段，不计入 PE 完整方法数量。5 类字段、10 个额外方法身份、1 个泛型字段、3 个类型槽、3 个 MethodSpec、2 份静态布局记录及既有离场载荷 2 个 MethodSpec 均核对。容量属性的整数成员位于 16，数组为 IReference[]，扩展接口声明顺序为 OnAlloc/OnRecycle，普通接口为 Clear。

冻结证据保留 `s_ReferenceCollections` 的原始布局标记 `0x040002d8` 与严格检查的 `0x020001f0`；getter、setter、回收检查和静态初始化分别核对到同一原生槽 `0x93436a0`。不会把静态标记剥除后伪装成完整静态字段运行时。4 个辅助函数没有匹配到注册方法身份，报告明确保存 false。

暂存联合验证 1,105 项 Java（29 类）通过，其中本批 90 项；8 项 Python 原件检查通过。本批为新能力和构造入口抽取，没有现有生产行为先失败记录，不将编译或新增功能缺失计为生产 RED。全量 `scripts/build.ps1`、10,523 项 Java（413 类）通过；既有 717 项 Python 全量与后续十七批共 136 项独立检查通过（未重跑完整 Python 集合，既有脚本文件哈希未变）。3,023 个源码文件、151 份协议快照核对通过；结果为 `build/rogue-reference-pool-verification.json`，封存 JAR 为 `build/rogue-reference-pool-10523-certified.jar`，SHA `8b54b9e06bbc6cb8ae8dcc3c5d0b837d50b11275c46d24955ce3a70db3c5d951`。
