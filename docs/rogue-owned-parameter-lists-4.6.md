# 4.6 离场与不可选中登记列表

普通登记迁移使用两个明确的引用列表：List<GOCCDKLAIKG> 和 List<LJGNANFNLDF>。上一参数与替换参数是同一个引用时直接返回，包括两者皆空，不读取列表或世界。空替换引用表示撤销；列表按引用身份移除第一项，重复登记的后续项保留。同实体的新参数先撤销旧登记，再追加新登记。

列表移除先核对有效存储前缀，再查找首个匹配引用；找到后先减少数量、移动后续引用、清空尾槽，最后增加版本。未匹配不改变头部。添加先增加版本，再要求存储；空容量扩到四，满容量翻倍并保留有效引用。缺失存储、无效数量、容量上限或后续失败保留已经发生的版本和数量变化。本实现明确限于项目内已编译的引用容器和 255 项边界，没有声明通用原生比较器或完整 CLR 数组实现。

离场可见性读取最初捕获的列表数量和数组，按顺序查找参数第二个布尔字段。遇到首个 true 即停止，不访问后续无效项。刷新将可见性设置为该聚合值的反值，立即参数为 true，原因值为 30；缺失可见性组件时跳过设置。之后重新读取当前列表的存在性，只有从无登记变为有登记或反过来时才调用明确绑定的离场事件路径。事件工厂、事件结构与分发函数体仍待完成。

不可选中参数来自不同实体时，先要求两个实体引用，调用已核对身份的错误记录函数并返回，不修改列表。同实体或单侧为空的普通迁移先移除、追加，随后要求关联实体；技能组件存在时才请求刷新自身状态。错误记录、查询和刷新失败均保留成功前缀。
