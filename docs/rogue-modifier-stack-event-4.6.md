# 4.6 修改器叠加事件

`RogueModifierStackEvent46` 补入叠加事件中明确的层数、参数帧、版本和事件调用顺序。层数、强制层数及最大层数直接复用替换及数值绑定状态，实际替换调用与标准变量通知已联合验证；真实属性、战技点、行为事件和所属实体事件的处理体仍由明确绑定提供，没有安装在线实例。

先创建参数对象，记录配置增加量：强制层数存在时该值为0，否则为当时的层数增加量。先推入参数栈，再捕获当前层数，之后再次读取强制层数；不存在时增加运算按Int32溢出。第一轮设置仅在值变化时通知，通知回调可以改变当前层数和最大层数。再读取当前层数及按Int32相加的最大层数，最大值下限为1，对层数只做上限裁剪，不补造非负下限。第二轮发生变化时再次通知。

实际层数变化在两轮设置后重读层数，再以Int64减去推栈后的旧层数。它可达正负4,294,967,295，不按Int32截断。参数对象中的配置增量与实际变化分别编码；绝对值小于1,073,741,824使用标准模式，其他有限层数差使用扩展模式。本批不因此开放扩展变量单元。

随后解除叠加属性，读取当前附加战技点列表长度（空引用为0）并写入暂存计数，再调用战技点与回调装饰器解除叠加。读取此时配置决定是否绑定行为特效，配置缺失会失败。这些实际处理体、容器及属性修改仍待实现，调用到绑定不能作为处理完成证明。
