# 4.6 修改器叠加模式分支

`RogueModifierStackMode46` 补入原件普通路径中，已解析输入和显式状态下的寿命/计数叠加分支，以及三个独立数值设置器。状态复用 `RogueModifierLifetime46.State`，永久标记与后续寿命推进读取同一对象。这里只覆盖 `_ProcessModifierRedd` 的模式分支，没有建立实际修改器、选择待叠加实例或安装战斗世界；宇宙仍为 `partial`。

## 已补入的模式行为

`ModifierStacking` 有14个值。它与标记来源类别的 `ModifierStackingFlag` 不同，不能把角色技能、装备或宇宙来源当成叠加模式。

| 模式 | 寿命 | 计数与替换 |
| --- | --- | --- |
| 2 Refresh | 覆盖当前寿命，然后把当时当前值赋给初始寿命 | 保留计数，不调用替换 |
| 3 Prolong | 输入为-1或初始寿命为-1时永久，否则以Int32回绕相加；再重设初始寿命 | 保留计数，不调用替换 |
| 5/7/8/12 Replace / ReplaceByCaster / ReplaceByCasterOrUnStack / ReplaceByCasterAbility | 覆盖当前寿命，再重设初始寿命 | 更新计数，然后调用显式替换 |
| 6 Merge | 输入为-1或初始寿命为-1时永久，否则取当前/输入最大值；再重设初始寿命 | 保留计数，调用显式替换 |
| 10 ReplaceButKeepLifeTime | 保留两个寿命字段 | 更新计数，调用显式替换 |
| 0/1/4/9/11/13 | 模式分支不更新这些字段 | 模式分支不调用上述回调；仍不能据此宣称完整模式无需处理 |

独立设置器先比较旧值，相同时不通知；改变时先写值，再按层数0、计数1、寿命3调用显式通知。寿命设置器本身不重设初始寿命。模式中的初始寿命赋值发生在寿命回调返回后，因此回调改变当前寿命时保留其新值；计数和替换回调发生在初始值赋完以后。异常保留已完成写入，中断后续动作，不额外回滚或补发通知。

项目仅接受已匹配的模式0～13，超出范围在任何写入之前拒绝。有限分支没有对计数、层数、寿命作额外钳制。模式参数中的寿命和计数已经由上层解析，尚未把这段分支接到实际参数对象或实例注册表。
