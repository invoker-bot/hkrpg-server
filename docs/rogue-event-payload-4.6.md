# 4.6 事件载荷初始化与清空

事件载荷初始化创建独立的空实体引用列表，读取显式共享目录的 JsonEnumStatic.None 引用，再创建三个数值槽和三个字符串槽。None 是对象引用，没有被替换成整数零、字符串或项目自建哨兵；目录可以显式提供空引用。完整载荷扩展已有离场事件的所属实体投影，两级分发和归还仍使用同一个对象。

清空先释放所属实体、实体、触发信息和两项组件引用，再清实体列表。列表版本先加一，数量先归零；原数量为零或负数时跳过存储，正数时清有效前缀。缺失存储或容量错误时头部修改保留，后续标志、数组和尾部引用仍保留。

列表清空成功后重置标志与部分可选对象，恢复当前目录的 None 引用，清属性原因和修改器事件，再依次将当前数值数组的前三槽归零、当前字符串数组的前三槽设空。原件在每个槽写入前重新读取当前数组字段；短数组已经写入的前缀保留。超过前三槽的尾部、数组对象和实体列表对象均保留，供后续复用。

上下文可为空。存在时要求内部值字典；该字典是 Dictionary<StringHash, FFKBNBIMMHE>，值保存对象引用。正数量先清空全部桶，再清数量及空闲列表向量，清旧有效条目前缀，最后增加版本。非正数量跳过存储并仅增加版本，数量和空闲向量不重置。条目为空槽表示默认归零的值结构，不代表未知游戏值。上下文对象和字典对象保留；最后才释放目标、技能和攻击等尾部引用。
