# 4.6 钟表剧情存档查询的资源读取

剧情记录越来越多时，同一次钟表查询会重复读取、计算相同四份卡牌表的完整 SHA256。本批把一次 `ClockParkState.valid` 内的整份已核对定义共享给本局、章节历史和已到达凭据；下一次调用重新读取当前文件。首次开场仍延迟读取卡牌，电影历史不新增抽奖表依赖。存档结构、原始公式、本服既有规则、奖励和协议保持原行为。

完整原始文件仍由 `ClockParkCards.load` 的固定 SHA 核对；共享对象只存在于这次校验的局部对象，未存入 Player、未按文件大小或修改时间建立跨查询缓存。小游戏和抽奖的公开入口继续重新核对原始卡牌，只有这次同根目录校验可以复用已经通过的定义。目录查询还去掉了锁内重复执行同一份存档校验。

新回归 `ClockParkQueryResource46Test` 使用 JDK21 的实际 `jdk.FileRead` 记录完整资源文件的正字节读取；未按墙钟时间设置易波动阈值。在不可变上批产物 `6525ccb985ca4a8efe6a420f843faf82aeae074ad09bd667a6dd2b6cec4f52be` 上，三个原始玩法阶段及两种实际协议查询共五项先产生纯断言失败，六项资源变更、无关依赖和开场边界对照通过。302 / 410 / 420 阶段一次存档校验分别把每份卡牌表读了 6 / 2 / 8 次；420 的目录查询和当前剧情查询分别为 16 / 8 次。记录在 `build/clock-park-query-draft/native-red-v1`。

独立 Java 编译仅覆盖四份本批生产源码，其他生产类仍来自不可变上批产物。相同十一项回归全部通过：每份表在各阶段、各次调用及两种协议查询均只有一次正字节读取。四份资源在一次成功查询后分别做相同大小、相同修改时间的字节变更，下一次原生查询仍拒绝且不写 Player；恢复原字节后重新成功。记录在 `build/clock-park-query-draft/owned-native-green-v1`，本批输入前后稳定。

随后独立重编既有钟表回归，并与本批十一项联合执行：838项既有回归和11项新回归全部通过，零失败、跳过或中止。`build/clock-park-query-draft/owned-peer-green-v1/verification.json` 记录每个生产类的实际 CodeSource、本批四份源码及全部回归输入的前后 SHA256；当前主工程输出未进入 classpath。这项独立验证不替代正式 Gradle 构建。

最初测量夹具误把 `PLAYER_DATA_ERROR` 的值写成了2901，四项对照因此失败；旧日志 `red-v1` 保留，这些失败不算生产缺陷。随后按实际 Retcode 枚举修正，并在同一旧产物上重新完成九项、十一项纯行为失败与对照。正式项目构建和新产物实际通信仍以本批统一验证记录为准。

这项改动减少剧情存档查询的重复磁盘读取，不代表全部活动完成，也没有证明网络延迟、官方正评级公式或游戏客户端界面。本机客户端完整函数的只读核对仍未给出服务器端公式，已有版本化本服计分规则保持。

正式联合专项414项以及全量507类/13,815项均为零失败、错误或跳过，2,544份编译输入前后保持相同。专项实际生成的冻结包`build/initial-query-cyrene-daily-origin-clock-runtime.jar`的SHA256为`258b6cdb5567db32e2a7a81a7907ba8e5fb71f3aa9bbfb47cd24bceeab508ff1`；全量重新执行test并复用该包，不能把shadowJar的UP-TO-DATE写成再次执行。

这个同包运行既有`scripts/smoke-clock-park-ranked-games.py`，实际报告为`build/clock-park-query-ranked-games-current-native.json`，SHA256为`7669e3ed102fbfd207a689b091299bd505aa291b0998dd5c808f968f55c6962a`。独占目录`build/smoke/clock-park-ranked-games-uie9qcfl`保存25份网络快照和25份H2检查：首次prepare只修改本隔离Player的明确等级/任务前置，随后24份inspect不修改Player或Lineup。1,901次真实请求、25次正常stop和24次同UID正常进程恢复全部通过。九种评级1至3结果与等待恢复，原311/411检查点自然通过后进入小游戏，312次实际摆放，范围外评级拒绝且不消耗游戏。这里核对实际BSON和还原ClockParkState，不冒称50次独立Morphia读取或所有检查均只读。报告没有统一检查总数，不补造这个计数。

等级/完成前置及运营窗口是明确隔离夹具，初始属性和累计评级为本服既有规则；夹具没有写骰子、属性或通关，没有记结局物品和剧情进度奖励。未执行原Act、未证实官方评分或抽牌分布、未运行游戏客户端UI，也不证明强杀/断电原子性。2,316份受守卫的源文件前后SHA保持相同。
