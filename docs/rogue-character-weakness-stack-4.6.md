# 4.6 角色弱点空槽、扩容和添加

四种普通操作按实际枚举分派：Override 0、Protected 1、Attach 2、Secret 3。搜索捕获对应占用数组，返回第一个未占用位置；全部占用时返回 -1。外层只扩容一次，再搜索一次，零容量仍保持零容量，不擅自补最小容量。

扩容以当前掩码栈长度的两倍分别申请掩码和占用数组。复制当前掩码数组，再复制当前占用数组；两次复制都成功以后才发布新引用。任一数组缺失或复制越界时，两个原引用都保留，掩码、视图和脏标记不变。255 项上限属于工程保护，超过可翻倍容量时明确失败。

添加先完成空槽搜索与必要扩容，读取当前占用数组并写入 true，再读取当前掩码数组并写入原始 damageMask，然后调用实际四类聚合和活动刷新，正常结束才返回位置。失败保留已完成的写入前缀：掩码数组缺失时保留占用位，通知失败时保留槽、视图和脏标记。占用的零值覆盖仍抑制默认回退。返回位置可直接用于已有撤销和叠层弱点回执。
