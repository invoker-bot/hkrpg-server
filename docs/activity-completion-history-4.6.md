# 活动完成记录与后续条件

本批修复四项原始时间轴活动目标 `6029846`—`6029849` 的完成记录查询，以及 `QuestClose` 对独立玩法存档的识别。活动属于原始 `30013 / 3001301` 非周期模块，来源与完整关卡定义继续按 [时间轴活动说明](timeline-activity-4.6.md) 固定核对。

## 行为

已完成的原始观察记录在活动时间窗口结束后仍可作为后续任务条件。查询必须保留原始配置、原始前置任务、三次来源绑定的状态变化、接取标识、完成时间及保存结构校验。活动列表展示和领奖仍通过活动窗口检查，到期后不会重新开放领奖。

`QuestClose` 与普通完成条件统一查询任务实际所属的保存域。时间轴活动、拳馆限时目标、拳馆常驻目标、地方传奇及骰子目标使用各自已有的来源校验；普通任务使用普通任务存档。只有 `CLOSED` 才满足 `QuestClose`，已完成但尚未领奖的 `FINISHED` 和领奖预约中的 `CLAIMING` 均不满足。无需复制一份普通任务记录来解锁，普通记录也不能替代活动的观察证明。

## 验证边界

新增 28 项 Java 回归，旧实现记录了 12 项真实行为失败：完成证明在活动到期后丢失、独立活动的已领奖记录未被条件识别，以及关闭记录重载后仍无法解锁。其余检查覆盖未领取、预约中、借用普通任务记录、损坏观察记录和原始前置任务失效。测试中的关闭阶段通过原有阶段方法设置，不代表这些单元测试实际发放了奖励；原始网络领奖证据另行核对。

恢复检查读取前序时间轴活动的两份独立 H2 存档。它们分别由完整原始柱体与球体定义的实际原生请求产生四项接取、十二次有效状态报送和四次原始领奖。每份存档用本批固定产物在两个独立进程中恢复并校验，不写玩家或库存。到期窗口和使用 `QuestClose` 的后续面板为明确隔离夹具；原始活动面板 `30013` 的二十项目标未全部实现，本批不宣称整个活动完成。

最终构建、固定产物、正常服务进程检查与恢复结果以 `build/timeline-completion-history-verification.json` 为准。真实游戏界面、全部剧情演出、全部活动目标及断电事务原子性未验收。

最终完整构建为 12,821 项 Java 测试、475 个类全部通过；相关检查 312 项、六个类通过，2,410 份编译输入的 SHA256 保持一致。固定产物 `build/timeline-completion-history-certified.jar` 的 SHA256 为 `258c7d86db75d2e2ea515e141d027520f948851a66ecf86a417e8d72a58917ae`。源件集合 3,379 份与 151 份冻结协议一致，两次登录服务检查及账号进程恢复通过。

当前产物的恢复检查共四个独立进程，核对两份数据库中共八项原始已领奖目标和 24 条不同观察收据。前序网络证据的产物与报告指纹保持独立，218 次前序请求未在本轮重跑，也不计作当前产物的新请求。本轮实跑两项 Python 源件打包检查，新恢复脚本通过实际执行及语法检查；384 份已追踪 Python 源件未变，延续前一提交的 1,136 项累计证据，未重跑整套 Python。
