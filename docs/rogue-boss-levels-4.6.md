# 经典宇宙 Boss 固定等级

4.6 原始 `RogueAreaConfig.DisplayMonsterMap` 为 32 个经典区域提供 14 至 90 的预览等级。上一批世界内容绑定虽然使用正确的原始 NPC 和关卡波次，实际 `EntityMonster.customLevel` 仍为零，未把覆盖等级传入战斗。九个世界的新增回归均真实先失败。

本服采用明确的 Boss 固定等级策略：该世界预览必须非空、最多五种怪物、全部等级相同且为 1 至 100，至少一个预览 ID 对应实际来源 NPC 或关卡波次。原始预览可以使用不同的怪物变体 ID，不将它们替换进原始战斗名单。此策略不等于官方等级算法；普通房间、精英等级、HardLevelGroup、Boss 机制和能力的完整消费仍需补齐。

新局与世界内容计划一并保存等级、原始预览副本和“已计划等级”标记。创建 NPC 前核对保存来源和当前区域表；实际 NPC 设置该等级，战斗构造器沿已有路径把它发送到每个波次的 `monster_param.level`（冻结 4.6 定义：波次字段 2，参数等级字段 1）。未修改生成协议、命令号或版本号。区域预览、保存等级、保存标记或实际来源变化时，关闭该遭遇，保留已有选择，不另选怪物或重新缩放。

已保存的旧世界内容计划没有等级字段时，保留原先零覆盖等级的行为。缺少世界内容计划的更早探索继续保留原始房间绑定。实际入战核对 NPC 等级及全部波次，结算检查被冻结的 NPC 和波次对象及其等级；战斗中改等级、删除或替换波次不能推进本次宇宙清房、积分或结算记录。其他玩法的战斗输入验证不在本批范围。

新增 71 项 Java 回归覆盖全部 32 区域、八种坏来源、九种重载后的来源变化、八种坏计划、源预览修改不污染保存副本、JSON 旧格式、五种入战或战斗中损坏，以及两次实际 Player/Morphia 保存重读。六项提前死亡收据检查含正常计数及 NPC/波次变更；通过宇宙管理器和直接冻结死亡上下文调用均验证，三项真实先失败。九项初始等级行为失败及三项死亡收据失败分别保留在 `build/rogue-boss-levels-behavior-red.xml` 和 `build/rogue-boss-level-deaths-behavior-red.xml`；沿用上一批十一份固定来源和 85 条完整原始记录，来源见 [世界 Boss 绑定](rogue-world-boss-encounters-4.6.md)。

32 账号矩阵还复现旧 ID 生成器的密集请求冲突及账号覆盖，已以实际存储回归修复，见 [账号密集创建](account-id-bursts.md)。

原生探针新增每个战斗波次的固定 4.6 字段检查，以及 H2 恢复后的等级计划逐字段检查。执行 `python -s -X utf8 scripts/smoke-rogue-world-bosses.py --all-classic-areas` 可验证全部 32 区域，默认仍检查九个首次难度区域。每个区域使用独立 UID，首站分配共享 Boss 房、解锁置零均为明确隔离夹具；地图、关卡、波次和区域预览来自完整原件。实际请求数、战斗数、正常重启、钱包和输入 SHA256 以本批最终同产物报告为准。

最终两份产物分别通过 896 次真实 UDP/KCP 请求、32 场原始 Boss 战斗、32 次场景移除、重复结果拒绝和积分通知。每份 128 个会话快照、三次正常 stop 和三份离线 H2 矩阵共核对 96 份玩家记录；32 个 UID 的世界、怪物选择、14 至 90 级的原始预览副本及实际波次等级均恢复，钱包只保留实际掉落。2,258 份来源资源前后 SHA256 不变。第一世界入口的 31 次请求及探索积分的 58 次请求也在最终根产物重测通过。

全量及独立源码构建各 5,502 项 Java 回归通过，两份源码各 132 项 Python 检查通过，151 份冻结协议字节保持一致。本批 71 项等级/死亡收据检查和 14 项账号检查，共 15 项真实先失败。通用 4.6 服务的 47 项检查与 33 项玩家快照、Dispatch 两项检查和正常账号恢复通过。2,325 份源码逐文件匹配及两份 jar 的具体摘要保留在 `build/rogue-boss-levels5502-verification.json`。

这些检查不代表走完原始地图、官方难度缩放、完整战斗动作、剧情前置或游戏客户端 UI 验收。整体模拟宇宙功能保持部分支持。
