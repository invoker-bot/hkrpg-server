# 4.6 普通动态单元的标准数吸附

`RogueResonanceAdsorption46` 实现已匹配 PropertyAdsorptionConfig helper 的有限分支，普通 `RogueResonanceDynamicCell46` 增加显式配置构造器。三个参数的既有构造器继续表示空配置；getter 不执行吸附，lookup 写入先裁剪，再吸附，最后以固定标量替换旧值表达式。真实战斗配置加载、属性单元和原始调度仍未接入。

## 来源和数值范围

冻结夹具保存三个完整 PE 方法共 1,706 字节：74692 吸附 helper、68474 FixPoint 乘法、68481 FixPoint 除法。Math.Pow 的元数据方法 3059 跳转至吸附调用目标，只有五字节 JMP，没有 PE 完整方法范围，不包含邻近 IEEERemainder。十进制底数来自 RVA `0x40e6890` 的八字节 double 10；ZERO/ONE 使用此前核对的两组初始化对，共 32 字节。加减法的既有完整读取与有限指令证据继续沿用，不把片段当作完整方法。

配置字段 AdsorptionThresh 为 `+0x10` 的 FixPoint，FractionalDigit 为 `+0x18` 的 Int32。比例为 `10^FractionalDigit` 经原生 double 转 Int32 后再编码：开放 0–9 的精确整数比例；所有负小数位得到零比例，阈值乘积为零，直接保留输入。大于 9 会进入原生扩展编码，本项目明确拒绝；不把该值静默当作九位或零。输入、阈值和参与运算的中间结果限于标准编码；任何扩展结果在单元赋值前拒绝。

## 执行顺序

先求阈值乘比例，结果不大于 ZERO 则返回，不计算输入余数。阈值为正时，用 `0x1fffffffe` 提取标准数小数部分，与比例相乘后再次提取小数部分；负值使用向下取整后的非负余数，不能改为 Java 有符号取模。

余数小于 ONE/2 时，与阈值比较并在距离小于或等于阈值时向下吸附；余数大于或等于 ONE/2 时，以 ONE 减余数的距离判断向上吸附。半点走上侧，不使用最近偶数舍入。修正量先除比例，再从原值减去或加到原值。乘除法和加减法复用后缀 VM 已匹配的标准量化，修正量小于最小标准单位时可能量化为零。

lookup 的裁剪在吸附之前。吸附后的保存词可能超出动态上下限，读取或有通知时的新 getter 会再次裁剪。动态上下限继续求值；每个 lookup 的复制模板保留自己的不可变吸附配置。通知异常仍保留已赋的吸附值；求值或吸附运算失败不替换旧值，1221 的完成状态保持 `0x7777`。
