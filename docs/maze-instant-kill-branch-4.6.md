# 瞬杀条件的逐目标分支

`PredicateTaskList` 现在支持明确的 `ByAllowInstantKill` / `TargetAlias.ParamEntity` 分支。每个实际命中怪物分别读取当前场景、身份、等级和放置标签，只向该目标对应的成功或失败叶传入单一目标。不会因为同批小怪满足条件而把精英、抗瞬杀或挑战目标一并视为满足。

已知不允许瞬杀是 false，可以选失败列表；缺少当前角色/目标身份、非法或未知标签、未知等级属于无法判断，两个列表均不执行。`Inverse` 只反转可判断结果，不把缺少上下文变成成功。实际玩家锁内重新检查当前队伍和存活角色，防止同编号替代对象或复用旧目标。没有命中目标的施放回调不能虚构 `ParamEntity`。

分支接入现有 `BattleService.attack` 的普通攻击与非战斗秘技命中路径；后者由当前框架的 hit 回调调度原始攻击叶。其他目标别名、包含该条件的复合表达式及未知字段仍不编译，不把外层未知条件展开为成功叶。
