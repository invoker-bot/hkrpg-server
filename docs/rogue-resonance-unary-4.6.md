# 4.6 共鸣标准数的一元函数

本批新增 `ceil`、`abs`、`clamp01` 的标准数分支，并让已有有限后缀表达式调用它们。连同 `floor`、`round`，入口支持五种单参数函数。原有协议、命令号和生成类不变；这些数值能力没有自动绑定真实战斗变量或原始共鸣任务。

## 原生来源与边界

GEMGCCDGFGN 的回调 74385、74387、74388 对应注册键 `-514975797`、`368963114`、`1099313850`。注册名称、散列键、方法身份、三个完整 PE 回调（共 453 字节）与 FixPoint 初始化器（393 字节）均按固定本机 4.6 文件核对。

`ceil` 的标准数分支先检查小数位；整数输入直接返回原字，小数输入先按 floor 掩码取整，再通过 FixPoint 加法加 ONE。Java 在有符号标准数可表示的结果范围内保持这一行为。最高标准整数之后的小数会产生扩展结果，当前明确拒绝。精确 `Long.MIN_VALUE` 仍可直接返回。

`abs` 的标准分支使用 `neg` 和 `cmovs`，按取负后符号决定是否返回原字。特别是 `Long.MIN_VALUE` 取负溢出后仍然为负，原生返回该原字；Java 保留这个边界，不将它改成数学意义上无法用标准字表示的正值。

`clamp01` 先比较 ZERO 再比较 ONE，保留区间内的原始字。两个常量来自初始化器实际读取的两组 16 字节数据的第二个字，分别为零和 `1<<33`，再与回调/helper 中的 RIP 地址核对。标准加法和 Clamp01 helper 只核对 129 字节指令片段，不声称它们具有已匹配的完整原生方法范围。

三个新函数拒绝扩展编码输入。后缀调用仍要求一个参数，callee 必须为匹配的函数键；函数键不能作为普通数值变量读入。求值器仅解析实际数值参数，嵌套函数不会把函数键交给变量 resolver。其他注册函数和多参数调用仍未开启。
