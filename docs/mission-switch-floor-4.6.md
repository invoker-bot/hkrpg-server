# 4.6 命名剧情选择、离开楼层与书籍奖励

原始主任务4340104在20311/20311001上有两处SwitchFloor/NoPara目标，后继分别要求返回原楼层。之前没有读取TakeParamStrList，OldValue_0选择不能接取对应目标；普通楼层切换没有推进SwitchFloor，书籍190543奖励也没有实际入库。本批补齐这条服务器流程，内部协议基线仍为4.2.0，4.6字段与命令号快照没有改变。

命名条件仅支持明确的单个三元组：变量名、精确整数值、声明该变量的来源子任务。必须是同一原始任务图中的Former变量，值属于资源允许范围，来源子任务有完整完成记录且未取消。混合整数参数、未知变量、未知来源、错误身份/时间/任务图均不能打开分支。第三项按原始对话关联作保守的来源证明；参考项目没有提供这一字符串分支的完整解释，因此不宣称已独立核对官方客户端全部接取语义。旧整数CustomValue分支继续使用原有规则。

Player.loadScene在构造新场景及保存地点前，冻结当前普通世界中已接取的目标。完成实际加载后，核对目标、任务图、主/子任务记录、原始楼层和平面的对象及参数仍相符，再推进目标。只支持Town/Maze/Train、零维度、无剧情/试用/宇宙/任务副本上下文的明确原楼层NoPara形状；同楼层入口变化、初次加载、失败加载、单独地点回报及切换中才加入的目标不能消耗旧事件。到新楼层后，返回目标等到它自己的进入事件，不借用离开事件完成。

普通Usable/Book、AutoConversionItem、无UseDataID/返回物品且有正堆叠上限的书籍按实际背包堆叠交付。参考March7thHoney-OpenSource固定提交fe00bdbda3c28ca33d01f171566aa35b5ab95083、AGPL-3.0，GameServer/Game/Inventory/InventoryManager.Usable.cs的Book分支实际PutItem；实现为独立Java，没有导入参考二进制或运行依赖。书籍读取、收藏册统计和游戏UI仍未验收。
