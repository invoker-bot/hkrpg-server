# 4.6 共鸣标准数的多参数函数

本批补入 `min`、`max`、`clamp` 的标准数分支及后缀多参数调用。连同已匹配的一元函数，显式求值入口支持八个注册函数；原有协议、命令号、版本与生成类不变。有限数值求值还没有绑定真实战斗对象或原始任务调度。

## 原生来源与行为

本机 4.6 注册表中的 min/max/clamp 对应键 `339799074`、`696029444`、`-1355705909`，回调索引 74383、74384、74389。三个完整 PE 回调分别为 244、266、61 字节；完整参数调用器 70476 为 440 字节，完整 VM 70469 为 5,224 字节，五个方法共 6,235 字节。Clamp helper 68532 没有完整 PE 边界，只核对四段共 52 字节标准分支指令。

min/max 以第一个参数为初始值，单项直接返回，后续标准字逐项按有符号比较折叠。Java 有限入口接受 1–255 项标准字；空输入、超限、null 和扩展编码均拒绝。完整原生回调中的混合编码比较尚未开放。

clamp 顺序读取输入、下界、上界，跳到已匹配的 Clamp helper。输入严格小于下界时返回下界，否则再比较上界，保留原字；倒置范围不排序。输入等于下界时继续上界比较，可能返回上界。原生回调接受至少三项并忽略后续项，当前 Java 有限契约要求恰好三项，额外参数明确拒绝。

VM Call 的 unsigned byte 参数数量来自操作码后一个字节；跳表条目是相对表起点的有符号偏移。原生调用器逆向弹栈后写入参数数组相应下标，还原源参数顺序，再调用注册 delegate。Java 编译器先完整验证结构和函数元数，复制源表；求值时按源顺序求各参数一次，失败立即停止后续读取，callee 不进入数值 resolver。已有 255 字节程序、64 项栈与 32 层树深限制保留，因此后缀调用的实际参数上限受到结构限制。
