## 五星 UP 包含两段选择

官方详细规则把直接命中 UP 和从全部可获得五星中均等抽取分开描述。后一部分也包含当期 UP。一个 UP 加七个常驻候选时：

| 对象 | 没有 UP 大保底时 | 计入歪后必中后的长期五星 UP 占比 |
|---|---:|---:|
| 角色 | `50% + 50% / 8 = 56.25%` | `1 / (2 - 0.5625) = 69.5652%` |
| 光锥 | `75% + 25% / 8 = 78.125%` | `1 / (2 - 0.78125) = 82.0513%` |

长期占比是根据官方两段选择及歪后必中规则推导的值，不是逐抽出金概率。将它们乘以官方五星综合概率，分别约为 1.113% 和 1.534%，与官方详情给出的五星 UP 综合概率一致。本服自定义 UP 数量、与常驻重叠或显式 `eventChance` 会改变具体值；详情页按当前有效候选计算。

旧实现的五星第二段只抽常驻，遗漏了当期 UP；本轮改为全部可获得五星的去重合集，保持均匀选择。若在第二段抽中 UP，也清除大保底。群星、新手的角色/光锥分组规则不受此修改影响。

四星公开 UP 占比为角色池 50%、光锥池 75%，没有五星所述的额外全池选择规则。旧实现的四星第二段仍包含 UP，导致本机开放卡池无大保底时分别为 54.4118% 和 76.7857%；本轮从非 UP 四星中选择，使其回到 50% / 75%。UP 内均等抽取，未中后下次对应星级必 UP。

## 保底与逐抽概率

五星硬保底、四星十抽保底、四星/五星 UP 大保底和各类型继承需要一起计算。当前实现已有这些独立状态：角色活动池之间共享角色状态，光锥活动池之间共享光锥状态，群星、新手和另一个活动类型分别计数。五星优先时保留尚未兑现的四星 UP 保证，不能用获得五星来清除四星 UP 大保底。

本服五星软保底采用第 74 次起增加 6 个百分点、光锥第 66 次起增加 7 个百分点的兼容近似。公开详情没有提供完整逐抽软保底表；本轮未把该近似宣称为官方算法，也没有为凑综合概率而随意修改曲线。

对当前曲线进行完整保底状态计算，群星/角色五星综合概率约 1.605205%，四星约 13.056657%；光锥五星约 1.872272%，四星约 14.764399%。始发按完整五十次计算，五星约 2.080298%，四星约 12.166761%。这些是本服实现的计算结果，不等于官方公开值逐位一致。前三类的长期状态计算和始发的有限五十次计算采用各自适用的口径。

本服尚未接通当前官方五星自定义候选选择流程；候选仍由现有运营配置与资源校验决定。上述修复不代表完整复刻官服抽卡玩法、奖励经济、异常断电跨文档事务或真实客户端验收。功能状态继续为部分实现。
