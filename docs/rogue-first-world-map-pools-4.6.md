# 第一世界地图池与入口

原始区域 110 推导地图 101，七个原始站点为线性 1 至 7。原有 `RogueMapGen.json` 使用分支站点 21/31/71 等，缺少 2/3/7，导致第一世界在创建场景前返回 `ROGUE_AREA_INVALID`。新增可选 `data/RogueMapGenByMap.json` 按地图和站点配置候选房间，生产安装器仅补入不存在的文件；原有运营配置和数据库不覆盖。

默认仅为地图 101 指定 `1→304、2→302、3→303、4→304、5→305、6→306、7→307`。这是本服明确的房间分配策略。全部房间取自原始配置，最后的 Boss 波次 8003020/8003010 与第一世界预览一致；没有宣称复现官方随机地图生成。其余地图和未配置站点仍使用既有全局池；显式空池表示关闭该站点，不回退。

配置只接受已存在的地图、站点和房间，以及规范正整数键和实际整数房间 ID。整份配置验证后才发布，不静默过滤损坏项。地图必须有唯一入口，所有站点从入口可达，不能有重复站点、重复边、未知下一站、循环、自连或从其他地图混入的行。任意错误阻止开始探索，不发布半成品局或移动队伍。

固定来源为 TurnBasedGameData `724b139d8c9c32d12552eb95745a4fee72bfe48b`。夹具保留一条完整区域、七条完整地图和十四条完整房间记录，三份完整来源文件 SHA256 单独核对。小型单元夹具只将解锁字段设为零并提供明确场景；来源原件没有修改。

参考 hkrpg-go 的 AGPL-3.0 提交 `ef47e49a233133c46d70ab5a4deb4bc71ae49571` 中 `gdconf/rogue_map_gen.go` 的第一世界七站房间类别顺序。该实现从全部同类房间随机取值；本服使用匹配原始第一世界预览的指定房间和正常房类别 1，自有 Java 实现未导入参考运行时代码。

新增 23 项 Java 回归。原始第一世界入口在修复前真实失败，另覆盖十种损坏配置、九种损坏地图、空池、缺失可选配置的旧池兼容，以及安装默认时保留已有文件。源码导出将新增默认文件列为必需交付项。

`scripts/smoke-rogue-first-world-entry.py` 在标记的独立 `build/smoke` 目录运行。仅四项前置使用无奖励 Auto 夹具；区域、地图、房间、敌人权重、关卡和默认房间池不改写，地图配置由生产安装器实际补入。31 次固定 4.6 描述符的 UDP/KCP 请求核对登录、开始、七站快照、三组原始敌人、重复查询、未清房跳站拒绝和重连。四份同 UID 快照、三次正常 stop、三份只读 H2 Player 检查及两次进程重启保持相同房间分配和保存的加权选择，钱包和结算记录不增长。2,265 份输入资源前后完整字节 SHA256 相同。

该入口联调没有打完七个房间，没有验收完整官方前置、全部世界、剧情/事件分支、官方随机数、战斗输入回放、游戏 UI 或断电原子性。当前工程和独立源码副本全量构建、必要启动检查与最终 jar 核验以 build 认证报告为准；模拟宇宙整体仍为部分支持。
