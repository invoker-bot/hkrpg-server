# 4.6 经典宇宙战斗击杀与遭遇去重

原始 QuestData 4090301、4090303 使用 RogueKillBattleMonster（固定 Honey 枚举 752）、NoPara，要求 15 个、1,000 个战斗内击杀，AutoUnlock 无前置。原始奖励 113000、113001 分别发放 5、10 星琼。本批统计正式结算接受的死亡报告；一场胜利、一个场景怪物或原始波次人数均不能替代实际报告数量。

RogueBattleKills 在实际入战准备后冻结当前探索、入口/楼层/房间、原始组与唯一放置对象、RogueMonster 映射、正式 NPC/关卡/怪物资源，以及实际波次及各关卡怪物数量上限。结算前重新核对当前玩家、场景、队伍、资源身份和原始分配。死亡报告要求唯一正数实体编号、匹配关卡和怪物、人数不超原始名单；1/2 的计数分类沿用已有剧情击杀策略，0/3 不计数。未知或异常条目使本批报告不计数，不能只截取有效前缀。

BattleService 确认结算身份、统计和胜利后，在世界怪物移除前提交。每场有效计数的 battleId/timestamp 收据与永久 RogueBattleKillState 同存 Player，再刷新原始目标。另保存每局 site/room/plane/floor/group/instance 已击败场景怪物记录；已接受的原始胜利即使没有可计数报告，也保留实际场景怪物消耗，不把这份消耗记录当成击杀次数。UniverseEntityLoader 重建未清空房间时省略已击败遭遇，其他怪物保留，新局独立。

RogueBattleKillQuests 校验原始目标、参数形状、来源身份、实际历史、进度和完成时间。查询可补回已保存但未刷新的目标进度；伪造完成或历史损坏不能展示或领取。两档奖励实际合计 15 星琼，沿用预约领取和确认收据防重。

45 项专项检查覆盖 14/15、999/1,000 阈值、原始两只战斗怪物、两种可计数死亡来源、未报告/存活/逃脱/失败/退出不补计、重复与并发结算及领奖、未知名单和混合无效报告、源绑定改变、损坏/溢出历史与收据、保存先于目标和场景移除通知、进度恢复、未领取和已领取两组实际 Player/Morphia 二次重读，以及部分房间的原始遭遇重载去重。固定夹具保留 19 条完整原始记录、14 份文件、源提交和原件/blob 哈希。领域检查隔离楼层为原始组 3、队伍为测试角色；部分房间检查的额外存活怪物是明确的清房边界替身，不冒充原始放置。

首次有效红报告 21 项中 15 项为行为断言失败，源绑定三项及部分房间重载一项另有真实先失败报告，共 19 项。已清空房间的重载对照原本通过；通知观察器的编译错误另存，均不计为行为回归失败。

## 原生验证

```powershell
python scripts/smoke-rogue-battle-kill-quests.py --target 15
python scripts/smoke-rogue-battle-kill-quests.py --target 1000
```

连接器进入原始房间 100、入口 8000101、楼层 80001001，实际攻击组 3、实例 200001、NPC8011020，核对原始关卡 80010011 与两只战斗怪物 8011020/8011010，再发送已有 4.6 正式胜利结算和死亡报告。每次结算前必须观察匹配的目标进度和原场景怪物移除；相同结果立即重试必须失败。查询确认该遭遇消失且其他原始怪物仍在，再实际退出并放弃后开下一局。15 个目标的最后一场仅报告一个有效击杀，不凭胜利补成两个。

首个连接完成一个原始遭遇、计数 2，然后离开并正常关服。下一进程以同 UID 重读进度，实际恢复原探索，检查已击败的原始组 3 遭遇消失、其他原始怪物保留，再继续原始目标并实际领奖。同进程重连与第二次正常 H2 重启核对计数、钱包、领奖状态和拒绝重复支付。首房池及 1000201 无奖励自动前置图属于隔离夹具；原始房间、放置组、战斗名单、任务阈值和奖励不改，不预写击杀数、消耗收据、完成或星琼，初始碎片保留 50。

最终全量构建、独立源码包、当前 jar 原生正向链和来源复核以 `build/battlekillquests-4567-source-verification.json` 为准；报告通过前，不将本批标为最终验证完成。测试连接器是外部测试源码，不进入服务产物，也不改冻结协议或版本声明。

死亡信息和胜利是通过现有输入边界验证的客户端报告，本批不回放战斗输入，不证明完整伤害/回合模拟、召唤增援名单或官方原生成就完成条件。本批初始基线的组映射沿用旧项目策略；后续原始权重选择与非首项结算范围见[怪物权重](rogue-monster-selection-4.6.md)，原冻结证明不改写。完整教程、官方房间生成、所有宇宙模式、游戏 UI 和断电原子性仍待完成或验收，功能保持部分实现。
