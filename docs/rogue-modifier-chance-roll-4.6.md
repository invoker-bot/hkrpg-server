# 4.6 修改器命中、免疫与抵抗决定

`RogueModifierChanceRoll46` 补入明确世界接口下的原始决定顺序与三项结果：最终命中、原始概率命中、抗性后的实际概率。它调用已核对的有限抗性算术。世界归属、免疫表、事件池、逻辑随机状态和实际效果实例仍需真实绑定；本批没有接入线上战斗，宇宙玩法继续为 `partial`。

## 决定顺序

先查修改器状态表，再取目标组件和定义。行为69 `AlwaysSuccess` 直接成功并返回负 One 哨兵，跳过来源归属、免疫及随机。随后核对来源实际归属。行为10 `Shield` 遇到目标行为70时，仅接受来源归属等于目标或 `CharacterDataComponent.Summoner`；使用对象身份，缺失归属与缺失召唤者比较相等。目标行为83触发显式护盾转换通知，并返回不命中、原始命中、Zero。

正常路径依次执行行为免疫和状态免疫两个查询，前者为真也继续后者。免疫结果先于负概率旁路；状态类型2才发免疫通知，传原始来源与当时的定义标志。标志缺失时需绑定真实空列表，不能伪造事件池。非免疫负概率返回成功与负 One，不抽样也不读后续属性。

非负概率先算 `base = chance × (One + extraHit)`，从目标世界的逻辑随机来源只抽样一次，然后取来源 Anti 列表和当前定义标志，计算 `actual = base × (One - property135) × (One - maxBehaviorResistance)`。两次比较共用同一个样本，均包含等号；概率不统一限幅或整数舍入。项目只接受标准定点编码、0含～One不含的投影样本和最多255项访问，未匹配的编码与范围继续拒绝。

正常返回前回收已取得的同一个非空引用列表，包括空列表对象。计算或回收异常不额外执行 `finally` 回收。仅当原始概率命中、实际概率未命中时，回收后用当时的定义标志和原始来源执行抵抗序列。接口必须保持原件的缺失组件、空标志与状态类型0行为；没有以默认免疫结果代替实际表。

## 原件与回归

独立核对11个完整PE方法共13,149字节、9类字段和2个真实 `GetComponent` 泛型参数。包含原始入口、FixPoint常量构造、完整决定方法、状态表查询、来源归属、两种免疫、抗性、Anti列表、抵抗回调和随机调用包装。修改器入口读取结果的前两字节与 `baseHit && !successful` 一致。
