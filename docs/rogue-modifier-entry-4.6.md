# 六条原始效果任务的有限入口

Java 的 `RogueAddModifierEntry46` 接入既有 OnAdd 编译器的明确效果子任务工厂，覆盖九条经典共鸣中实际出现的六条 `Caster` / 字面量 `AddModifier` 配置。它先读取明确来源，再检查魅惑动作；跳过时不选择目标、不附加效果。普通分支使用原生默认存活掩码 `1`，按目标顺序调用绑定的效果执行接口；空目标直接完成，非空目标在完成通知返回后才完成。

该入口不会把来源实体当作上下文所有者。来源由 `get_SourceEntity` 获取，原生收尾通知使用另一条上下文所有者读取；二者可能不同。效果执行接口仍负责定义查找、资格检查、施加者继承和实际效果，收尾接口负责对应的所有者/目标通知。没有明确接口时无法通过编译器预检，不能以空实现冒充完成。

## 原件与缺省字段

冻结夹具为 `src/test/resources/fixtures/rogue-modifier-entry-4.6.json`，归一化 LF 的 SHA 为 `a2b89c701f6c452541f1c304e54d9da0c2ffbd515288b5583d927058dbb0abaa`。五个完整 PE 方法合计 10,316 字节，分别包含配置构造器、动态字符串读取、来源读取、目标求值和效果任务入口。完整范围由 PE 异常表核对，片段不扩大成完整方法。

构造器明确写入 `AliveOnly=true`；Chance 与 MaxTargetCount 都是原始定点数 `-8589934592`，即 `-1` 哨兵，不解释为负概率或目标数量。UI 两项开关、合并消息及固定位置默认为 true，消息间隔为 float `-1`。原始六条配置只设置 Caster 和字面量名称；省略使能仍沿用原始 TaskConfig 的 true，未将省略的字段物化进原始记录。

`GetComponent` 的泛型 MethodSpec 单独核对：方法定义 502972 的实际类参数是类型 54850 `TurnBasedAbilityComponent`，检查字段 `bIsInCharmAction` 的实例偏移为 `0x2b4`。这不是推测的状态标签。枚举声明已匹配，但 U16 常量编码尚不由通用分析器解释；存活掩码 `1` 来自完整入口的实际分支指令，不能据枚举名称声称所有常量已解析。

## 验证边界

三项真实断言先失败：普通入口顺序、魅惑跳过、执行异常保留 READY。实现后 29 项 Java 和 10 项 Python 来源回归通过，覆盖来源/目标异常、多目标部分成功、收尾异常、重复 begin、reset、空目标和六条原始 OnAdd 编译链。六条链的查询和创建来自既有真实表读取，效果执行使用明确测试绑定；这不是在线实体效果。

任务没有额外的执行一次保护：直接重复 begin 会再次执行绑定。首次执行异常保留 READY；已成功的任务再次 begin 后发生异常，保留原 SUCCESS，匹配入口没有起始状态重写的边界。先前目标效果不自动回滚。完整效果系统未来应提供其原生叠层与去重行为，不能用入口的状态代替。

255 个目标上限、非空来源/目标校验和不可变目标快照是明确项目边界；原生池化列表的可变语义未声称等价。未实现动态字符串变量分支、完整概率/目标数量语义、定义解析、附加条件、施加者继承、叠层/回调/寿命、原生收尾通知或客户端演出；完整效果运行时、在线战斗、真实游戏 UI 和全部玩法仍待完成，功能保持 partial。

全量 `scripts/build.ps1`、9,099 项 Java（377 个测试类）和 534 项 Python 均通过；2,807 个交付源码文件、151 份协议快照核对通过。结果为 `build/rogue-modifier-entry-verification.json`，封存 JAR 为 `build/rogue-modifier-entry-9099-certified.jar`，SHA `d96e0f5efe8814e8404dd1613b23225496396eac0e0b64406e4797ca93ac2bfb`。
