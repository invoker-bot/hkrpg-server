# 4.6 经典宇宙原始怪物权重与重载

原始 RogueRoom 的 GroupWithContent 引用 RogueMonsterGroup，后者的 RogueMonsterListAndWeight 决定可用 RogueMonster。原实现固定以 content × 10 + 1 取行，使原始 3008 组只能生成 30081，遗漏 30082 与 31011/31012/31013 三种扑满遭遇。该组的完整权重为 9/9/4/4/4，本批按原始非负整数权重选择，零权重没有抽取区间。

RogueMonsterSelection 校验当前探索分配、原始房间与放置组、入口/楼层、唯一原始放置和全部正权重候选的 NPC、VerseSimulation 关卡及战斗怪物资源。每局以 site/room/plane/floor/group 保存 Choice，包含选中映射、NPC、关卡和完整源权重，先保存 Player 再创建场景怪物。重载复用已有选择，源权重、资源或存档损坏时拒绝重新抽取；保存失败撤销尚未发布的选择。

UniverseManager 的入战准备与 CombatMonster 快照、RogueBattleKills 的原始遭遇绑定都读取实际已保存的选择。不能只在场景加载时随机、结算时仍校验固定第一项。入战后替换相同值的源组也不能通过旧绑定领取击杀或碎片。既有未配置怪物组表的隔离旧基线保留原查找兼容；实际配置表存在但缺行、为空或损坏时关闭回退。

33 项专项检查覆盖原始五种遭遇实际生成、30 个权重票的准确区间、零权重与八类非法权重、缺组不回退、重载不重复保存、八类源/存档损坏、正权重候选缓存身份、原始扑满波次实际结算和击杀计数、入战源绑定替换、保存失败、4096 选择容量边界、四类原始放置异常，以及两次实际 Player/Morphia 重读后的原 NPC/关卡/权重恢复。固定夹具保留 29 条完整原始记录、10 份文件、固定数据提交和原件/blob 哈希。领域楼层只安装原始组 58，出战角色与测试存储是明确隔离夹具。

原固定第一项的 1 项回归先失败，候选缓存身份错误另有 1 项先失败；实际非首项扑满已生成却不能推进战斗击杀的 26 项报告中另有 1 项行为失败，修复入战准备后通过。共 3 项有效先失败，不把工具错误计入回归失败。

```powershell
python scripts/smoke-rogue-monster-selection.py
```

初始碎片保留原始 50。首房池及 1000201 无奖励自动前置图属于隔离夹具；原始房间、组、NPC、怪物组完整权重、关卡名单、成就目标和奖励不改，不预写选择、击杀、消耗记录、完成或星琼，不预先设置随机结果。连接器在外部编译，不进入服务产物。最终产物的正向原生流程、全量构建、独立源码包和来源复核以 `build/encounters-4600-source-verification.json` 为准；报告通过前不标为最终验证完成。
