# 4.6 弱点组件创建、目录、查询和释放

普通组件工厂创建独立特殊列表，开启通知，保存允许为空的 owner，按原顺序创建覆盖、附加、保护、秘密四类掩码及占用数组。每个数组初始长度均为 4，内容为零或 false；类别掩码、活动/全部掩码及脏标记保持零值，最后创建视图列表。容量来自实际静态初始化的立即数 4，与构造函数八次读取的同一静态槽逐项核对，不是根据参考版本推定。

目录工厂保留客户端原始顺序 1、2、4、8、16、32、64。来源追踪包含七项数组的完整初始化方法、字段使用 kind 4 分派、字段引用、声明类型及第 392761 项字段的静态数据。显式 Catalog 实例可被多个 World 共用；目录适配器每次读取当前 types 引用，通知由明确绑定的回调执行。不会自动安装到尚未完成的世界或原生 NotifyManager 调度体。

查询返回当前原始掩码或当前列表引用，不触发刷新。IsProtected 和 IsSecret 使用原件的有符号正值交集判断，只有符号位的交集返回 false；HasSecret 使用非零判断，符号位非零仍返回 true。列表允许为空，查询不会补默认容器。

释放先清空 owner，再清空捕获的视图列表；视图为空时跳过清空，随后释放全部八个数组引用。特殊列表、视图字段引用、所有掩码、脏标记和通知开关保留。清空视图失败时，owner 已清空而数组保留；清空回调替换视图字段时仍清空最初捕获的列表，后续释放数组不重读或再次清空新列表。
