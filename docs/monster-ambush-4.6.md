# 怪物主动攻击时提示数值参数不存在

## 实机记录与原因

2026-10-23，用户确认报错在怪物主动攻击时出现。短时、限量的只读网络记录捕获到两次 `SceneCastSkillCsReq`：2026-10-22 UTC 21:00:13 / 21:01:23（本地 05:00:13 / 05:01:23），技能流水号 395 / 396，施放者实体 39，标签 `[1]`，空命中及辅助列表；服务器均返回 5。记录只保留攻击字段和回复码，不含登录凭据。

随后只读在线快照确认，实体 39 是基座舱段 `P20001 / F20001001 / G21 / 200001` 的原始怪物 `8012030`，事件 `20001003`；角色实体为 1 和 2。技能流水号不在场景实体表中。这个错误码对应“数值参数不存在”，不能据此认定资源文件缺失。

`Battle46` 把无辅助列表的怪物施放者一律解释为“玩家攻击怪物”的直接目标形式，进而用技能流水号查找玩家实体。此外，投射物回调校验只允许玩家施放者。两处都会拒绝合法怪物回调；原先测试把技能流水号与怪物实体号设成相同值且不带标签，因此漏掉了实际客户端形式。

## 修复边界

原生请求继续使用 `attacked_by_entity_id` 解析当前场景中的施放者；`cast_entity_id` 保持技能流水号并原样回传。只有使用当前场景角色编号并明确携带能力名的旧式直接目标请求才反向解释字段。真实怪物的普通攻击允许已知回调阶段，不套用玩家技能的投射物声明或秘技耗点规则。

空命中回调成功结束但不创建战斗；明确命中当前队伍角色才通过既有战斗服务进入伏击，保留实际怪物阵容、伏击效果、胜败结算和剧情目标推进。未知施放者、非法目标、错误技能索引或能力名、非法标签和缺失关卡继续拒绝。玩家技能、可破坏物以及原有显式直接目标入口保留相邻回归。

没有重置 UID 10001、预先击败怪物或改写剧情目标。银狼登场过场和对话缺失是另一项尚未确定根因的问题，不计入本次修复。只读核对已确认其任务及演出配置在当前客户端设计数据中存在，随后也找到 `Story100010101` 对话记录并通过所在数据块 MD5 校验。资源清单的 9,456 条块记录在 Persistent/StreamingAssets 下均有对应文件，大小全部吻合；此项仅核对文件存在和大小，未验证全部块的内容哈希，也未把具体 Timeline 路径解析到资源块，不能证明素材已经加载或播放。
