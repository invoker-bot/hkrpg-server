在原始 40431 Default/TrialOrPlayer 入口基础上，扩展实际世界等级 1 至 6 的 source1 难度。原有世界0行为保留；空偏好和 Default 使用实际世界，Easy 只降低战斗有效世界一档。试用角色 1021409 的等级、装备、成长和技能预设始终依据实际玩家世界，不随简单战斗难度降级。Source1 支持范围仍明确限于已核对的 40431 与 43306，不能据此放行其他副本或未证明的世界等级。

资源提交为 `TurnBasedGameData@724b139d8c9c32d12552eb95745a4fee72bfe48b`。夹具保留前批完整入口、34项原始子任务和三份脚本，另加入七档事件及五份缺少的技能预设；29份原始 Git 文件、126份完整记录与本机资源逐项核对。战斗 204310700 至 204310706 的原始等级依次是 24、32、40、48、56、66、88；试用角色对应实际世界等级为 40、40、50、58、68、78、80。原始特殊胜利条件保留，没有代造客户端胜利字符串。
