## 验证边界

新增 23 项 Java 回归，五项有效场景在修复前真实失败，删减原始性别候选的边界另有一项真实失败。覆盖男女主角、错误性别、两种性别同时存在、缺失资源、残留替换队员、普通队伍冒充临时队伍、附加客户端动作、缺失实际角色、损坏参数、32 次并发刷新和 JSON 恢复。早期编译错误不计入行为先失败。

单元测试明确预置接取、当前场景及发布队伍，以隔离技能计划验证身份。独立进程检查另读取真实安装资源，使用生产 TrialManager 构建五个原始角色：每个均有七项实际技能及一件装备，五个条件全部满足，核对实际核心队伍和战斗消息。2,271 份输入资源前后完整字节 SHA256 不变。这一检查仍手动发布隔离队伍，没有验证官方前置、自动角色生命周期、客户端入口或游戏 UI；本批没有新增 KCP 正向流程。

当前工程和独立源码副本的全量构建、资源检查与冻结协议核验以最终 build 认证报告为准。协议、命令号、生成类及版本声明保持原样。
