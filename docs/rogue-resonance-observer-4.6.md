# 4.6 数值容器的有限实例通知监听

`RogueResonanceObserver46` 补入有限实例监听的添加、移除和固定调用列表。`RogueResonanceVariables46` 的普通写入、注入及既有投影写入通知路径接入同一根容器监听；旧构造回调继续保留。注册或移除投影容器上的监听仍拒绝，没有安装原生委托或容器工厂。

监听身份由明确实例目标和已解析方法身份组成，使用对象身份比较。添加保留顺序与重复项；移除从末尾找最后一个相同目标/方法组合，回调对象本身不参与比较。没有移除构造时的旧回调，也没有开放静态委托、不同委托类型、整段多播子序列或一般反射方法等价判断。

一次通知先捕获不可修改的监听列表，再调用旧构造回调，之后按捕获顺序调用附加监听。回调期间添加或移除监听不改变本次列表；嵌套通知捕获当时的新列表，外层恢复后继续旧列表。异常停止后续监听，并保留此前写入和监听变更。

实际根容器写入先提交单元再通知。既有普通写入包括同值写入仍通知，保留上一个值及存在标志；注入始终通知，上一个值缺席。投影单元写入继续使用根容器监视器，只有存在构造或附加监听时才为通知再次求值，保持原来的无监听路径。每个根容器最多255个附加监听是本工程有限执行保护，没有把它写成原生委托限制。
