# 4.6 事件分发与执行列表归还

Java 21 RogueEventFire46 补入 EventManager.FireEvent、GetExecuteList 和 ReleaseExecuteList 的普通分支控制。既有监听管理器 State 新增明确的 executeListPool 字段16；字段24监听表和既有撤回行为不变。池泛型独立核对为 Queue<PooledList<OnEventCallBack>>，不是栈；接口层供应先进先出的出队/入队。

分发先要求事件，再依次通过明确绑定取得源实体ID和事件类型，组成低32位源ID/高32位事件类型的同一Key；随后才要求接收管理器/监听表。第一次查询缺失直接返回；命中后重新读取管理器当前监听表，再查询同一Key。第二次缺失也返回；否则从捕获的第二份字典重新读取当前数组及监听列表。源ID和事件类型不重新求值，负整数原始位保留。

执行队列为空/数量非正时分配并初始化执行列表，初始化允许收到空分配结果，由调用者其后检查；数量正时从队列头取出。分发要求所得列表非空，调用明确的 PooledList.AddRange 复制监听。先读执行列表当前数量；每个非空回调先读取一次判空，再重新读取实际回调调用，随后重新读取当前数量。监听源集合的增删不会改变夹具中已复制的列表；当前执行副本的变更与递归分发各自独立覆盖。

正常完成后调用明确的 PooledList.Release(TRUE)，再读取管理器当前队列，归还执行列表。这个 TRUE 的完整语义尚未独立匹配，不命名为保持容量或普通清空。回调、复制、Release 或入队异常传播且保留已完成的状态；不引入finally自动归还。独立Release入口先检查列表，执行Release后才要求管理器和当前队列，因此空管理器仍保留Release前缀。
