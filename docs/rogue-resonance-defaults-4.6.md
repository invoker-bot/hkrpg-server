# 共鸣固定变量的原始默认范围

`RogueResonanceVariables46.fromSourceDefaults` 补入未序列化范围的标准固定变量初始化。原始下限、上限保留为客户端的扩展定点数编码，变量值和写入仍限定标准编码。四个原始声明已用于属性→表达式→舍入→floor 的隔离组合回归；真实战斗上下文、参数、属性、目标和效果调度仍待接入，功能为 `partial`。

## 原生依据

固定 4.6 客户端的二进制读取器 74469、cell 创建方法 74759 和 FixPoint 静态初始化 68417 共三个完整 PE 方法、4,968 字节保存在冻结夹具。读取器在未序列化范围的分支保留两个静态常量，再将它们作为上下限传入创建方法；后者裁剪初始值，并保存值、下限、上限。这里核对的是实际二进制读取器，没有把 JSON 转换方法当成同一方法。

下限原始字为 `-6710886399932891135`，上限为 `6710886399932891137`；它们按扩展编码分别表示 `-99999999999` 和 `99999999999`。读取器的 RIP 目标与常量初始化写入位置相互匹配。所有有符号标准编码均位于这一区间内部，因此默认容器初始化与写入保留原始标准字，不需要扩大现有通用 clamp 的接受范围。

原始记录仍为 `Config/ConfigAbility/BattleEvent/Avatar_RogueBattleevent126_Ability.json`、键 `de3a20f8ec6dd787`、8,124 字节、SHA `ff7bcb003aa6a8a701f6f05db5ee9cbb798681a399dec21bc189f4aae55b82a2`。第三条能力的四个变量均为固定零值、读取类型零、无序列化范围；来源工具拒绝记录身份、键、值、读取类型、范围或路径改变。

## 有限行为

新工厂接收明确提供的固定声明并复制输入，构建尚未发布的容器，不发送初始化通知。写入继续使用既有 setter 的缺失键忽略和写后通知语义。默认上下限可读取；一般容器的自定义标准上下限行为保持原有规则。调用方必须已确定声明来自未序列化范围的固定变量，工厂不负责解析或猜测来源。

扩展变量值、一般混合编码 clamp、原始序列化自定义范围和动态 provider 没有开放。最多 255 个声明是本项目的有限边界。默认边界确定不代表 TaskContext 选取或完整能力调度已经实现。
