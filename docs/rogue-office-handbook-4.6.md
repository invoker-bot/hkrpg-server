# 漫游测试后的办公室图鉴装置（4.6）

## 现场与依据

UID 10001 已完成漫游测试的首领和战后对白，子任务 403000222「使用图鉴」进行中；玩家实际操作办公室的图鉴装置时显示「图鉴装置暂未开放」。这不是仍需重打首领。

办公室楼层 80112001 的原始组 3 / 实例 300003 / 装置 1005 初始为 `Closed`。机械臂原始图表在 `Closed` 状态显示上述提示，在 `Open` 状态打开图鉴并产生 `RogueHandbook_Open`。任务 403000222 的脚本等待这个字符串，然后报告 `Mission_403000222`；主任务 4030002 以该子任务作为完成条件。原任务脚本中的两个 `ChangePropState` 缺少目标和状态参数，所以此处的确切服务端动作无法从资源直接还原。

## 本次修复和边界

这是限定兼容实现：当原始办公室、装置、任务定义及前置记录匹配，且第一次测试已经结束、第二次测试的首领结算及后续对白完成、图鉴目标已接取时，将该装置恢复为 `Open`。在已加载场景接取目标时向客户端发送装置刷新；进入场景时也会依据已存任务状态恢复。不会改写角色、背包、战斗胜利或任务记录，也不会代替玩家打开图鉴或伪造任务完成回执。实际打开图鉴后的完成仍由客户端的任务回执驱动。

正常第一世界的资源解锁链为 12001 → 11 和 11007，要求两个教学主任务 4030001、4030002 及开拓任务 1010403 均完成。10001 当前后一个开拓任务尚未接取，因此不能据此提前开放全部关卡。[漫游测试任务流程](https://wiki.biligame.com/sr/%E6%A8%A1%E6%8B%9F%E5%AE%87%E5%AE%99%E2%80%A2%E6%BC%AB%E6%B8%B8%E6%B5%8B%E8%AF%95)也将使用图鉴列为后续目标；[模拟宇宙·其一](https://wiki.biligame.com/sr/%E6%A8%A1%E6%8B%9F%E5%AE%87%E5%AE%99%E2%80%A2%E5%85%B6%E4%B8%80)列出了后续主线前置。项目的正常模拟宇宙仍属部分实现，此处不代表后续各世界已全部可玩。

## 验证

修复前先复现已接取目标的装置仍为关闭、场景内接取目标不刷新、完成任务后仍关闭。新增回归覆盖前置及取消状态、任务不提前结束、任务回执防重、第一世界前置、原生 4.6 装置刷新、图鉴目标和任务完成后的 H2 正常重开。主任务原始奖励配置也在隔离测试中核对并检查一次性发放；该测试的库存发放使用替身，不能证明真实客户端奖励表现或断电原子性。

`scripts/build.ps1 -TestForks 8` 通过，640 个测试类、15,827 项测试无失败、错误或跳过；其中图鉴专项 8 项。H2 重开在同一测试 JVM 中执行，4.6 刷新测试解析实际出站协议，但这两项都不是网络 KCP 或真实客户端验收。

本轮不宣称真实客户端交互、最终奖励界面或全部模拟宇宙玩法已验收。隔离测试使用原始配置切片，源文件摘要保存在 `src/test/resources/fixtures/rogue-office-handbook-4.6.json`。
