# 4.6 共鸣余数、比较和条件表达式

本批在 Java 后缀求值器补入操作码 6–13、15：余数、六种比较、三元选择和逻辑非。十八个原始 Byte 操作码均有明确的有限标准数行为；数值函数仍采用上一批十五键的有限契约。协议、命令号、版本、生成类和运营资源没有随此改变。

## 原生来源与求值规则

完整 VM 70469、Approximately 68530 和 FixPoint 初始化器 68417 共三个 PE 方法、5,943 字节，18 项相对跳表和 Byte 常量已核对。Sub 与 IsAlmostZero 68531 没有完整 PE 边界，分别记录 298、322 字节指令片段，共 620 字节；ONE 的实际十六字节初始化对单独核对，不将指令前缀冒充完整方法。

Equal 调用 Approximately，NotEqual 对同一结果取反，差值绝对值严格小于原字 8588 时视为近似相等。Less/Greater 先排除近似相等，再按有符号原字比较；LessOrEqual/GreaterOrEqual 接受对应严格方向或近似相等。近似值可能同时满足两个含等号方向，并不满足两个严格方向；不能替换成普通 Java 比较。布尔值实际入栈为 ZERO 或 `1<<33`，可以继续参与标准数运算。

IsAlmostZero 同样采用严格 8588 阈值，包含正负对称窗口。其标准最小字有单独分支，使用初始化器给出的正扩展最大值继续比较，结果为 false。Java 以无溢出的范围判断保留这一结果。近似比较用 BigInteger 差值绝对值，避免两端相减溢出误判为近零；原生 Sub 的扩大/裁剪路径已核对，远距离差值不会落回近零窗口。扩展输入仍未开放。

Not 对“接近零”返回 ONE，其他值返回 ZERO。Ternary 的输入顺序为 condition、whenTrue、whenFalse：VM 已先将两个分支求值入栈，再调用 IsAlmostZero 并选择原字。Java 显式按源顺序求条件和两个分支各一次，接近零选择 false 分支，否则选择 true 分支。未选择分支中的缺失变量、扩展值或除零仍会报错；这不是 Java 的短路条件表达式。

Modulo 沿用已匹配的标准原字余数：保持被除数符号，零除数明确拒绝。新操作同样在编译时完整验证栈和返回结构，保留 255 字节程序、64 项栈、32 层树深与源表复制；未知操作码仍拒绝。
