# 探索入战标记的按序移除

`AddAdventureModifier` 的无条件添加保留旧版定义查询结果，实际施放标记在对应动作执行时加入；不会在前面的动作执行前暴露后面的脚本添加。插件通过现有 `addAdventureModifier` 明确设置的默认值，仍在本次施放开始时生效，即使同名标记也由脚本添加。

`RemoveAdventureModifier` 仅支持完整类型名、非明确客户端专属、非空名称和严格的 `TargetAlias/Caster` 对象。带未知字段、其他目标或缺失目标的移除不执行。它只删除当前角色当前技能的本次施放元数据中的对应名称，不清除其他名称、共享定义、其他角色或独立技能的快照。下一次施放重新初始化，再按实际条件及脚本顺序执行添加、移除。

释放、攻击、命中回调以及条件成功分支均覆盖。原始黄泉 `LocalPlayer_Acheron_NormalAtk01` 的 `OnStart/0` 完整移除对象保存在 `maze-modifier-removal-4.6.json`，资源提交为 `724b139d8c9c32d12552eb95745a4fee72bfe48b`，同时记录文件和 Git 原始对象 SHA。验证时明确设置旧标记并隔离调用该叶；未改任务对象，没有声称整条黄泉普攻或原始攻击时序已接通。
