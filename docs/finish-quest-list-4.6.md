# 4.6 剧情任务完成列表

固定4.6资源的72条FinishQuest剧情条件全部使用ListContain/ParamIntList，原实现只读取ParamInt1，既不能推进正常列表，也可能误用额外整数跳过列表。FinishQuestMissionCounts按不同来源任务的实际完成数量推进，达到原始Progress才执行既有动作并冻结奖励。目标定义须同时属于实际MissionInfo及GameplayDefinitions，父任务和目标须有效进行且未取消；列表要求非空、最多256项、不重复的正编号，目标为正且不超过列表长度，无附加整数、字符串或道具参数。

每个来源须有编号匹配的QuestData及FinishWay，且来源目标为正。只读取QuestType=1/4的普通任务存档，核对存档键/编号、FINISHED/CLAIMING/CLOSED、正完成时间及其自身FinishWay目标进度。来源目标不是一律1：原始2200801/2200802要求4步，2200803/2200804要求3步，而剧情401010004只要求其中一项任务完成；401012001要求四项2200647至2200650完成。损坏来源不计数，其他正常来源照常计数；未知定义/规则/形状不补造，已观察到的历史进度不倒退。

QuestType=3周期任务及5日常任务不从普通questStates借取旧记录，相关列表目前保留未支持。72条原始条件中55条仅引用普通任务，17条包含周期任务；107个引用编号中90个普通、17个周期。这是资源分类，不是55条官方玩法验收。来源任务的小游戏、酒饮、经营、物件等实际完成事件仍需逐项补齐。Honey固定AGPL提交fe00bdbda3c28ca33d01f171566aa35b5ab95083的MissionHandlerFinishQuest仅在Quest分支计数，Mission分支为空；没有把这个参考入口当作完成玩法，也没有导入其代码。列表门槛采用原始配置推断，本机原生条件执行器尚未独立验证。

fixtures/finish-quest-list-4.6.json保存29条完整原件、九个源文件及SHA/Git原件SHA/路径，固定TurnBasedGameData提交724b139d8c9c32d12552eb95745a4fee72bfe48b。包含三个父任务完整总表、三个原始目标、三个MainMissionExcel、十个QuestData和十个FinishWay。测试只加载原始目标子集，父任务接取及已完成来源是明确夹具，不表示来源全部玩法完成。客户端回报正例的教程解锁任务4000001完成记录也是夹具，实际教程1000201未验证。
