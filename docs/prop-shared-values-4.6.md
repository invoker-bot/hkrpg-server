# 4.6 道具空共享值配置

169 份补充关卡组共包含 364 个道具，其中 114 个的原始 `ValueSource` 是空对象，没有 `Values` 字段。原有 `PropInfo.getSharedValueByKey()` 只检查外层对象，随后直接对缺失列表调用 `stream()`，因此查询这些合法空配置会抛出空指针异常。

现在外层对象或内层列表缺失时返回没有匹配值。保留原始对象及字段的缺失状态，不补空列表，不丢弃真实共享值；已有匹配键的字符串读取和缺少键的行为保持一致。

新增 4 项 Java 回归，其中空对象和显式空列表值的两项先复现失败，修复后全部通过。用打包服务端的实际资源解析器重新解析全部 169 个组，对 364 个道具执行共享值查询，确认 114 个缺失列表均安全返回，并按原始维度装载 167 个组、完成 21 个楼层初始化。

```powershell
./gradlew.bat test --tests '*PropSharedValue46Test' shadowJar
scripts/build.ps1
```

这项修复仅处理合法空配置的读取异常；不改变已有资源、协议字段或玩法奖励，也不证明完整脚本、弹药来源或游戏客户端已经验收。补充资源的来源和完整读取边界见 [关卡组恢复](client-runtime-groups-4.6.md)。
