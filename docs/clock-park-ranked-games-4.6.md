# 4.6 钟表小子正评级与本服累计规则

原始30208射击及41009/42009电影的评级0至3、胜利字段与等待类型沿用已限界的4.6客户端证据。正评级现在可以结束当前小游戏，再以实际属性计算原始321/411/421检查点。原始卡牌、行动、效果与常量仍校验完整固定来源；没有更改协议、命令号或运营资源。

官方AttributeChangeByGameScore的正评级公式尚无可靠证据。新等待明确保存本服规则`hkrpg.clockpark.project-cumulative-mini-grade.v2`，把原始ParamList作为本服分级增量，累计0至当前评级的项，再乘原始三属性系数。射击评级0/1/2/3分别增加A 0/2/4/6，B/C不变；两场电影分别增加A/B/C各0/1/2/3。第三剧本属性上限100，第四剧本60，与已校验原始常量一致。这是本服设计选择，不能当作已还原官方公式。

旧等待的`hkrpg.clockpark.original-mini-card-zero-grade.v1`与原来源完整保留。查询、恢复或新结果都不会把已有证明升级到新规则；旧等待仍只结算零评级，合法正评级保持FEATURE_SWITCH_CLOSED。新等待采用v2，旧小游戏历史和新等待可同处一局；每个ChapterReceipt按自己保存的规则和来源复算。

结果仍需要对应的当前剧本、原始回合、小游戏类型及合法胜利/评级组合。属性增量、胜利、实际评级、完成位和检查点同一次Player保存；保存失败回退原等待和原属性，一次重试只结算一次。重复及并发结果不能再次增加属性。负数、宽整数、越界评级、非法布尔/重复字段、false正评级和射击true/0继续拒绝。正评级不直接发结局物品或增加进度。

新回归的九个合法正评级原生断言在修改前全部真实失败，原返回FEATURE_SWITCH_CLOSED。89项扩展检查覆盖未封顶增量、封顶、电影C=24被正评级提升后真实通过411、保存中断、并发一次结算、来源/规则/结果/属性损坏、关闭活动、旧零规则与混合历史，以及34种真实Player/Morphia阶段各两次完整原生查询恢复。最终数量以测试XML和`build/clock-park-ranked-games-verification.json`为准，尚未产生最终报告的构建不能算已验收。

`scripts/smoke-clock-park-ranked-games.py`以真实保存的服务端面值走原始普通回合和检查点，分别结算三个小游戏的1/2/3评级。25次正常关服与同UID24轮H2进程恢复核对等待、评级后检查点、混合章节历史、完整原生查询、已保存小游戏卡面和正式钱包/队伍；越界与外来类型、重复结果不得消费或改变状态。进入420必须自然通过411，否则正式无奖励失败后重开，未写面值、属性或通过位。前置任务、等级21和运营窗口仍是明确隔离夹具。

本服评级结算接通不代表实际Unity小游戏或完整活动完成。官方公式、官方卡牌分布、Buff/无尽、完整剧情执行、其他活动与宇宙以及游戏UI验收仍待补齐；输入重演和异常断电原子性尚未验证，功能保持partial。
