# 4.6 修改器字符串注入

`RogueModifierStringInjection46` 补入明确版本列表的字符串注入，字典由 `StringDictionary` 绑定；`javaMap` 提供实际Java字典写入。修改器替换状态加入 `dynamicStrings`，与既有初始字符串列表字段使用同一状态。尚未安装原生字典工厂、真实世界和在线修改器实例。

空引用和空列表直接返回，不读取字典；这与数值注入的空引用失败入口不同。非空列表先捕获版本，每轮先检查版本，再读取当前长度和当前字典。处理中追加、移除、清空或替换列表元素都会使下一轮失败；即使最后一项写入后列表变空，仍先检查版本。已经写入的字符串保留，没有回滚。

传入列表是 `Injections`，所有改变内容的操作都推进版本，包括替换同值；普通Java列表没有本绑定所需的版本规则，因此不会被当作已匹配列表。列表捕获后，修改状态中的初始字符串列表字段不会让本次遍历改用新列表。此绑定按同线程修改器执行设计，没有声称支持并发修改或原生所有列表内部实现。

每轮重读当前字典，键保留32位哈希位模式，重复键覆盖旧值。字符串可以为空引用、空串、空白、Unicode或含零字符。字典操作异常保留此前操作及操作本身已经发生的修改。最多处理255项是本工程有限执行保护，没有把这个上限写成原生限制。

原件元素为 `GODJKFFNCNI`，装箱键和字符串分别位于16/24，内联列表元素步长16、键和值分别位于0/8。修改器字符串字典位于56，初始列表位于24。字典方法槽核对为 `Dictionary<StringHash,String>.set_Item`，方法定义12484，实例化参数位于MethodSpec的第8字节索引；键为值类型StringHash，值为内建STRING，不按字符串类型载荷推定类编号。

核对一个完整已定位方法共319字节、三类字段、一项泛型方法身份和两个泛型参数。另核对一个帮助函数的完整PE范围1,739字节，其中传入模式1走覆盖分支；该帮助函数没有匹配到注册方法身份，因此单独记录为原生运行函数，没有冒称为已识别的完整方法。原生桶、扩容、比较器和异常辅助体仍未实现，本Java使用明确绑定的字典操作。
