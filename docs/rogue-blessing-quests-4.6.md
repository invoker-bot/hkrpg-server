# 4.6 祝福图鉴任务与奖励

原始 `RogueBuffType.RugueBuffTypeRewardQuestList` 将九种命途与 53 个图鉴任务关联。普通前四档使用 QuestType 1，后续追加档及繁育、智识的部分档位使用 QuestType 3；这些关联的 Type 3 是永久图鉴记录，不能仅因编号相同而放入周期重置域。

`RogueBlessingQuests` 只统计已实际取得记录中的不同一级祝福编号。编号同时需要唯一的 RogueVersion 1 定义、IsShow 和对应一级 MazeBuff；隐藏共鸣、升级、同一祝福的再次取得、未知正数编号和重复定义均不会增加数量。任务沿用原始 Equal 条件和参数，达到目标才完成，不固定完成全部图鉴。缺失资源、损坏历史及保存记录的编号、阶段、进度或时间不一致时，查询和领取都保持关闭。

选择、商人购买、奇物实际授予祝福及骰子提交后的实际授予均接入任务刷新。预演不会修改任务。原始奖励继续经过 QuestManager 的预约、实际发放、确认流程；80 星琼普通档及 30 星琼追加档不重复发放。部分或中断发放保留待核对状态，没有跨文档断电原子性或自动对账保证。九个同类普通成就仍沿用原始 FinishQuest 前置，本项不会将它们自动解锁；未关联的 Type 3 规则仍待单独确定作用域。

## 验证边界

新增 90 项 Java 回归。首轮 17 项在未实现基线上实际失败；查询防护另有六项行为失败，共 23 项有意义的先失败证据。反射字段名等测试夹具错误不计入先失败。53 档逐项验证差一个未完成、达到原始不同祝福数量才完成、原始奖励到账及重复拒绝；其余检查覆盖重复取得、隐藏祝福、命途隔离、异常资源/存档、24 次并发领取及两次真实 Player/Morphia 恢复。普通成就前置保持另有回归。

`scripts/smoke-rogue-shop.py --verify-handbook-blessing-quests` 通过真实 UDP/KCP 购买原始祝福，显式查询全部 53 个关联目标并核对实际进度通知，随后检查同 UID 重连、正常关服/H2 重启、结束探索及再次重启。网络场景的首房、商人入口和 300 初始碎片是明确隔离夹具；原始祝福、目标和奖励不改。本项网络流程仅取得一个不同祝福，要求全部档位保持未完成、星琼不增加，不能据此宣称 80/30 星琼的网络正向领取或全部九种命途已逐一通过网络。

当前核对输出以 `build/blessingquests-4364-source-verification.json` 为准；该文件产生前，本批全量、独立源码副本和最终网络复验仍未完成。真实游戏 UI、完整获取菜单与官方前置授权、全部宇宙/剧情/活动玩法及断电恢复继续补齐。
