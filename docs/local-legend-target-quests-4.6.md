# 4.6 传奇挑战目标任务关联范围

后续已接入专用战斗入口、实际目标写入、正式/试用隔离队伍、原始奖励和正常 H2 网络恢复，见[专用入口与结算范围](local-legend-dedicated-entry-4.6.md)。下文的 50 项检查和“尚未发布”描述保留该阶段的验证边界；官方客户端和整组 BattleChallenge 仍未完成。

`LocalLegendQuests` 将已保存且绑定当前原始资源的目标历史关联到 `LocalLegendFinishBattleTarget` 任务。接入的是 25 条明确目标规则：10 条下一难度解锁任务、10 条普通/困难主目标奖励任务，以及 5 条困难目标附加任务。资源提交固定为 `724b139d8c9c32d12552eb95745a4fee72bfe48b`。下一难度依对应主目标完成解锁，不要求上一难度全部侧目标达成。

观察器只接纳原始 `Equal`、进度 1、明确正目标 ID、无额外参数、无前置的 `AutoUnlock` 任务；目标必须存在于当前传奇挑战目录。普通类型 1 任务沿用普通接受过程，类型 3 奖励任务只有实际目标历史存在才建立记录，并通过既有 Quest 查询和领取入口返回。空查询不创建活动任务，不给奖励或完成位；伪造已完成 Quest、侧目标、外关目标和损坏历史不能满足主目标或解锁下一难度。源规则缺失、变形或目录重排后，保留已有记录并关闭发布/领取，不重写操作员资源或重映射旧目标位。

奖励沿用原始 RewardData 和既有先保存预留、再实际发放、最后确认领取的流程。普通难度每项为星琼 40、信用点 40,000、素材 213 × 4；困难难度每项为星琼 30、素材 110222 × 6。5 条附加困难任务的原始 RewardID 100 是空奖励，不能补造物品。已领和正在发放的记录不能重复付款；部分发放或预留保存失败不会自动重试发奖，仍需既有人工核对流程。

50 项新增检查使用 65 条完整原始记录，保存各表来源提交与 SHA；最初 22 项检查中的 21 项真实断言在接入前失败。覆盖 10 条解锁、10 条奖励、5 条空奖励任务、17 种源规则变形、目录重排、无历史查询、并发重复领取、部分发放和保存失败。实际 Player/Morphia 文档两次保存/读取保持已完成、预留、已领取三种状态；4.6 Quest 协议字节保留实际任务 ID 和进度。

目标历史写入和物品投递在专项测试中是明确夹具；该检查不代表传奇挑战的真实战斗已完成或正式背包/H2网络领取验收。既有完整服务网络检查覆盖普通日常战斗和非法统计拒绝，专用传奇挑战入场、正式/试用隔离队伍、实际当前战斗目标写入、活动/剧情门槛、专用查询/通知、正常 H2 恢复以及官方游戏 UI 仍需继续补齐。其余 `BattleChallenge` 奖励规则没有按任务 ID 排序或“全部星级”猜测完成。

最终全量构建、独立源码构建、冻结协议与网络检查以对应验证记录为准；本轮未执行官方客户端，不声明其已验收。
