# 4.6 探索技能组合条件分支

探索技能解析器现在为 `PredicateTaskList` 的 `ByCompareCarryMazebuff`、`ByAnd`、`ByAny` 建立运行时分支。整棵已支持条件树在实际施放者的效果锁中使用同一时刻求值，再释放锁执行成功或失败动作；`Inverse` 作用于它所在的完整条件。释放、普通攻击和命中回调分别读取该时刻的角色状态，技能复用时重新检查，不把效果过期视为仍持有。

含未知条件、其他目标、空列表、非法布尔值或非整数效果编号的组合树不展开任一分支。原始银狼新形态的MP/自动恢复判断、三月七新形态的技能类型/目标组合树，保持完整原始任务及来源SHA作为负向夹具；相关输入尚未接通，不能因为成功列表含有添加效果或修饰器就认定它们已触发。

固定资源的本地角色配置审计读取18条 `ByAnd`/`ByAny` 原始任务，当前均含尚未支持的移动、目标、动态值或其他判断。正向分支测试将原始砂金效果任务中的条件对象保持原样，放入明确标注的隔离分支结构；它验证条件执行器，不证明原始整条技能已运行。新增21项Java回归中16项修复前真实断言失败，涵盖四种效果组合、组合反向、过期、攻击/命中、复用、原始混合树拒绝与非法结构。旧单一持有效果条件与来源保持兼容。

未知非组合条件的完整解释器、分支状态跨异步事件、条件内探索修饰器与TriggerBattle全局设置、完整移动/距离/投射物判断仍待完成；没有新增组合分支正向KCP或真实游戏UI验收。原始客户端文件、151份冻结协议与既有资源不修改。
